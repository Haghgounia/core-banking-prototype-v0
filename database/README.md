# Oracle database scripts

ساختار این شاخه براساس **مالک فیزیکی اشیای Oracle** تنظیم شده است.

```text
database/oracle/
├── geo/
│   ├── ddl/
│   └── data/
└── dps/
    ├── ddl/
    └── data/
```

- `GEO`: جداول فعال اطلاعات پایه. تفکیک منطقی ماژول اطلاعات پایه در کد انجام شده است، اما جداول در این فاز هنوز در Schema `GEO` باقی می‌مانند.
- `DPS`: Schema محصول‌ساز سپرده. تا زمان دریافت DDL و Data Script واقعی، هیچ جدول یا اسکریپت فرضی برای آن ساخته نمی‌شود.

اسکریپت‌های DDL و Data باید تا حد ممکن همان خروجی تولیدشده از Oracle/SQL Developer باشند. تغییر دستی فقط برای موارد مستند و ضروری انجام شود.
