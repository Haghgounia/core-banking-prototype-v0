# CIF Reference Data - Contact and Geography Phase 3

این بسته اکنون شامل 9 جدول و 36 Seed Row است: 8 جدول فاز اصلی + جدول محلی `REF_ADDRESS_SOURCE` با 3 مقدار عملیاتی فرم نشانی در `0.3.22-fix9`.

جداول کشور/استان/شهر/منطقه/زبان ایجاد نمی‌شوند و GEO منبع اصلی باقی می‌ماند.

`REF_ADDRESS_SOURCE` فقط برای `PARTY_ADDRESS.SOURCE_CODE` استفاده می‌شود و Vocabulary آن از فرم عملیاتی Party می‌آید: «اظهار مشتری»، «سامانه پست»، «مدرک سکونت». این جدول از `REF_DATA_SOURCE` عمومی جدا نگه داشته شده است.
