PATCH: DPS2 Account Lifecycle R8A Template Hotfix
BASE: PATCH-DPS2-ACCOUNT-LIFECYCLE-R8
TYPE: Patch-only / no DDL / no backend change / no UX change

ROOT CAUSE
The R8 Angular template opened @if(servicingControls();as wa){ before Step 01 and kept the control-flow block open past the closing </section> of the selected-account detail grid. Static content checks did not detect this cross-boundary Angular template structure. Angular compiler therefore reported NG5002 Unexpected closing tag "section" near line 830.

FIX
1. Close the servicingControls Angular control-flow block immediately after the Step 02 lifecycle/hold article and before Step 03 / term operations.
2. Extend the R8 verifier with a regression check that servicing control-flow closes before later Step sections.
