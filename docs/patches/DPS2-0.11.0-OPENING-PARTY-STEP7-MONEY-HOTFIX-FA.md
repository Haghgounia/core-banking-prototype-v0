# DPS2 0.11.0 - Opening Party / Step 7 / Money Hotfix

Base: `core-banking-prototype-v0-2026-09-30-1331.zip` plus the previously supplied Opening alignment/template/tax-binding patches.

## Changes

- Party owner editor now uses a selectable Party ID list sourced from ACTIVE Party search results and existing linked owners; rows can be re-opened for edit.
- Opening obligations remain limited to `INITIAL_BALANCE`; `OPENING_FEE`, `CARD_FEE`, and `CHEQUEBOOK_FEE` are not generated by the reviewed Opening wizard.
- Step 7 now exposes the reviewed four-action lifecycle. `Create Account` runs runtime preflight, checks, aggregate persistence, and account creation in sequence instead of requiring a separate visible `Persist Opening` action.
- Settlement reference is system-generated when settlement starts if not already present.
- Activation/readiness evidence includes CBI/SIAH, final compliance recheck, restrictions readiness, account-opened SMS evidence, and joint-commercial confirmation when applicable.
- Monetary inputs and monetary displays use comma delimiters (for example `10,000,000`).
