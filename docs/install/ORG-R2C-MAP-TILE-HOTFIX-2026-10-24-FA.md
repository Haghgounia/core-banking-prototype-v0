# اصلاح نمایش نقشه شعب و واحدها — ORG R2-C / Map Tile Hotfix

## علت

سرویس زمینه نقشه CARTO برای دریافت کاشی‌های بدون کلید API تصویر «API KEY REQUIRED» برمی‌گرداند. بازیابی واحدها از Oracle و نشانگرهای نقشه مستقل از آن سرویس انجام می‌شود؛ در تصویر گزارش‌شده ۲۲۶ واحد فیلترشده دیده می‌شود.

## تغییرات سورس

- جایگزینی منبع تصویر زمینه نقشه با سرویس استاندارد OpenStreetMap (`https://tile.openstreetmap.org/{z}/{x}/{y}.png`)؛ بدون نیاز به کلید CARTO.
- اعمال منبع مشترک به هر دو فرم «نقشه استقرار شعب و واحدها» و «انتخاب مختصات روی نقشه».
- به‌روزرسانی استناد قابل مشاهده به مشارکت‌کنندگان OpenStreetMap؛ حذف اعتباردهی نادرست به CARTO.
- ارتقای آزمون `verify-org-r2c-map-ux.mjs` برای جلوگیری از بازگشت منبع CARTO بدون کلید.

هیچ تغییری در Oracle، API اطلاعات واحدها، اعتبارسنجی نشانی‌ها و ارقام مختصات انجام نشده است.

## نصب بر روی نسخه R2-C قبلی

۱. از سورس قبلی نسخه پشتیبان تهیه کنید.
۲. چهار فایل Hotfix را از ZIP در ریشه پروژه `D:\Projects\core-banking-prototype-v0` استخراج و فایل‌های موجود را جایگزین کنید. **کل محتوای پوشه frontend را حذف نکنید.**
۳. در CMD اجرا کنید:

```cmd
cd /d D:\Projects\core-banking-prototype-v0
node tools\verify-org-r2c-map-ux.mjs
node tools\verify-node-tool-path-portability.mjs
call bin\stop.cmd
call build-production.cmd
```

۴. تنها بعد از Build موفق، `call bin\start.cmd` را اجرا کنید و با `Ctrl+F5` مرورگر را بازنشانی کنید.
۵. مسیر `http://localhost:8091/#/organization/branch-map` را آزمایش کنید و سپس پنجره انتخاب مختصات از فرم نشانی را نیز باز کنید.

## ملاحظات سرویس زمینه نقشه

سرویس عمومی OpenStreetMap برای نمونه اولیه با تعداد کاربر محدود استفاده شده است. این سرویس SLA ندارد و استفاده گسترده سازمانی از آن مجاز نیست مگر با رعایت سیاست رسمی (https://operations.osmfoundation.org/policies/tiles/). برای استفاده بانکی در تولید، باید سرویس دارای قرارداد/کلید معتبر، یا زیرساخت کاشی خودمیزبان انتخاب شود. فایل منبع در `organization-map-tile-source.ts` متمرکز شده است.

**معیار پذیرش:** نقشه بدون متن API KEY REQUIRED ظاهر شود؛ آمار و نشانگرها همچنان درست باشند؛ انتساب OSM قابل مشاهده باشد؛ باز و انتخاب کردن مختصات نیز زمینه نقشه را نمایش دهد؛ بدون تغییر داده Oracle.
