2) Import تمیز تعرفه‌های بانک مرکزی ۱۴۰۴
------------------------------------------
از Root پروژه در SQL*Plus/SQLcl اجرا شود:
@database/oracle/fee/install-cbi-fee-1404.sql

این اسکریپت:
- 239 ردیف Excel را به 229 تعریف منطقی تبدیل می‌کند.
- 5 تعرفه ارزیابی را با 15 Tier درج می‌کند.
- درصدها را به RATE_VALUE اعشاری تبدیل می‌کند.
- فرمول‌های نامشخص را EXTERNAL_VALUE نگه می‌دارد.
- هیچ DELETE/TRUNCATE/DROP ندارد و قابل اجرای مجدد است.
- اجرای توصیه‌شده تراکنشی است: Import -> Verify -> COMMIT.
- اگر Import یا Verification خطا بدهد، قبل از Commit کل تغییرات همان اجرا Rollback می‌شود.

سه تناقض عددی منبع (Excel rows 45، 60، 154) عمداً Rule عددی اجرایی ندارند تا پس از تأیید منبع اصلاح شوند.

4) کنترل UI
------------

  رکوردهای رسمی بانک مرکزی با CLASSIFICATION_CODE=CBI_1404 قابل مشاهده‌اند.
