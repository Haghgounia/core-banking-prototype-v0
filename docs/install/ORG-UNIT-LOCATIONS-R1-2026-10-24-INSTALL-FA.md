## SQL در Oracle — **جدا از نصب برنامه**

در پوشه `database/oracle/org/unit-location-consolidation/` چهار فایل ۰۱ تا ۰۴ وجود دارد. ابتدا **فقط ۰۱** را با F5 اجرا و خروجی و Backup داده را بررسی کنید. فایل‌های ۰۲ و ۰۳ هر دو پیش‌فرض `APPLY_CHANGES = NO` دارند و با حالت پیش‌فرض هیچ چیز نمی‌نویسند؛ تغییر به `YES` تنها در محیط آزمون و پس از بررسی و تأیید DBA. فایل ۰۲ DDL و commit ضمنی دارد، فایل ۰۳ DML بدون COMMIT خودکار است. فایل ۰۴ را پیش از COMMIT روی **همان Connection** اجرا کنید.

**تا زمانی که باهم تطبیق نداده‌ایم، اسکریپت YES را اجرا نکنید.** هیچ تغییر یا حذف رکورد رسمی شعب، اصلاح کدپستی، شهر GEO، یا تعویض شناسه در Patch وجود ندارد.
