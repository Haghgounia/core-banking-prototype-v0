Core Banking Prototype 0.3.86 / FIX94

1) اگر از 0.3.85 ارتقا می دهید، برای FIX94 هیچ DDL/Migration جدیدی لازم نیست.
2) bin\stop.cmd را اجرا کنید.
3) Source/Patch نسخه 0.3.86 را روی نسخه قبلی قرار دهید.
4) build-production.cmd را اجرا کنید.
5) در خروجی Build کنترل کنید:
   Built version: 0.3.86
6) bin\start.cmd را اجرا کنید.
7) Header باید نسخه 0.3.86 را نشان دهد؛ سپس Ctrl+F5 بزنید.

کنترل عملکرد Time Picker
- مسیر: اطلاعات پایه > تقویم دو > الگوی هفتگی ساعات کاری
- روی آیکون ساعت یکی از فیلدهای شروع/پایان کلیک کنید.
- فهرست ساعت به صورت 24 ساعته و با گام 5 دقیقه نمایش داده می شود.
- تایپ مستقیم HH:mm نیز مجاز است.
- مقدار ذخیره شده در API/Oracle همچنان مانند 07:30 است.
