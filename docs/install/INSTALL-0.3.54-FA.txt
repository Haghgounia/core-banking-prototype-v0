Core Banking Prototype 0.3.54-prototype-fee-p1

روش ارتقای مطمئن:
1) نسخه را در یک پوشه کاملاً جدید Extract کنید.
2) bin\rebuild-and-start.cmd را اجرا کنید.
3) منتظر پیام Build موفق و Start برنامه بمانید.
4) فایل اجرایی همیشه app\core-banking-prototype.jar است.
5) در Header سامانه باید نسخه 0.3.54-prototype-fee-p1 نمایش داده شود.

کنترل قابلیت جدید:
- مسیر اطلاعات پایه > تقویم دو > مشاهده تقویم ماهانه را باز کنید.
- فرم باید با تقویم هجری شمسی و ماه جاری باز شود.
- ماه قبل/بعد، امروز، انتخاب سال/ماه و تغییر نوع تقویم به میلادی/قمری باید فعال باشد.
- مناسبت‌ها و تعطیلی‌های موجود در CAL2.EVENT_OCCURRENCE باید داخل روزهای ماه و پنل جزئیات دیده شوند.

کنترل نسخه Runtime:
- Build نسخه را در app\BUILD-VERSION ثبت می‌کند.
- start.cmd فقط وقتی JAR را اجرا می‌کند که BUILD-VERSION با VERSION یکسان باشد.
