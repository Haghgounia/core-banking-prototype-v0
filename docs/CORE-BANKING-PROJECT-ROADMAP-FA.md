## ۴-ب. ORG-04A — شروع یکپارچه‌سازی مکان و نشانی شعب، R1 (۲۴ اکتبر ۲۰۲۶)

**R1 در سند اولیه = SOURCE_READY / ORACLE_NOT_APPLIED (وضعیت تاریخی پیش از اجرای واقعی):** نمای یکپارچه **فقط خواندنی**، API فقط‌خواندنی، سنجش چندنشانی و چهار SQL مرحله‌ای (Preview → Additive Opt-in → Backfill Opt-in بدون Commit → Verify) تهیه شدند. هیچ جدول قبلی حذف یا تغییرنام نشده است. `LOCATION_ID` قدیمی و مراجع `SERVICE_POINTS` پابرجا هستند. پیش از CRUD و حذف فیزیکی، تطبیق واقعی داده‌های ثبت‌شده و رفع تعارض لازم است.

**R2 / OPEN:** فعال‌کردن CRUD تجمیعی و مدیریت جابه‌جایی/تاریخچه با تاریخ‌های غیرهم‌پوشان، کنترل نسخه، مسیر پایدار برای نقاط خدمت مستقل و آزمایش واقعی Oracle. محافظت از داده‌های رسمی شعب و ممنوعیت حدس GEO/نشانی همواره برقرار است.
