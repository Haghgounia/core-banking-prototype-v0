# محدوده اصلاحات ORG R2-C

**بر اساس فایل دریافتی ۲۰۲۶-۱۰-۲۴ ساعت ۱۷:۵۱**

## نشانی و موقعیت شعب و واحدها
- عنوان و صفحه به واژگان کسب‌وکاری تغییر کرد؛ توضیح انتقال اطلاعات و اعداد کنترل فنی از صفحه عملیاتی حذف شد.
- ثبت و ویرایش روی API مستقل مدیریت نشانی، با کنترل شماره نسخه و سوابق حسابرسی، باقی ماند.
- باز بودن فرم نوشتنی تنها پس از تأیید ساختار R2-B توسط Oracle است؛ سورس به‌تنهایی مجوز ثبت بدون سابقه ایجاد نمی‌کند.

## راه‌های ارتباطی
- عنوان اصلاح شد؛ گرید پس از انتخاب واحد خوانده می‌شود، بازخوانی دستی اضافه شد و پیام خالی بودن به زبان کاربر است.
- داده جدید منحصراً از اطلاعات ثبت‌شده ORG خوانده می‌شود؛ تلفن قدیمی نامعلوم و CIF بدون تطبیق/مالکیت داده متصل نمی‌شوند.
- لینک انتخاب واحد از نقشه به صفحه تماس اضافه شد.

## نقشه استقرار شعب و واحدها
- سرویس GET-only برای فهرست مرجع GEO و موقعیت شعب/واحدها اضافه شد.
- نمایش نقشه ایران با کاشی‌های CARTO، خوشه‌بندی نشانگرها، بزرگ‌نمایی/حرکت، فیلتر آبشاری واقعی و لینک‌های جزئیات ایجاد شد.
- سقف خروجی سرویس نقشه ۶۰۰۰ ردیف است؛ برای مختصات خارج ایران یا ناموجود نشانگر جعلی ساخته نمی‌شود.
- منوی ORG و دسترسی سریع به نقشه اضافه شد؛ جداول و مسیرهای سازگار قبلی حفظ شدند.

**بدون اجرای هرگونه دستور نوشتنی روی Oracle.**
