# فاز Deposit Product Factory

## محدوده فعلی

- نام قابلیت: `deposit-product-factory`
- Schema Oracle: `DPS`
- وضعیت: ۵۰ فرم مرجع `DPS.REF_*` فعال؛ جدول‌های عملیاتی محصول در انتظار تحلیل

## قواعد این فاز

1. منبع طراحی، اسکریپت‌های واقعی Oracle و Use Caseهای تأییدشده است.
2. هیچ جدول یا داده فرضی ساخته نمی‌شود.
3. هیچ Package یا Class برای حساب سپرده، مانده، سود، Posting یا حسابداری ایجاد نمی‌شود.
4. DDL در `database/oracle/dps/ddl` نگهداری می‌شود.
5. Data Script در `database/oracle/dps/data` نگهداری می‌شود.
6. داده ضروری و داده نمایشی باید از هم جدا باشند.
7. پس از تحلیل روابط و Constraintها، فقط کلاس‌های موردنیاز محصول‌ساز ایجاد می‌شوند.

## خروجی این مرحله

- نگهداری DDL، Sequence، Constraint، Index و Commentهای دریافت‌شده از Oracle
- فعال‌سازی ۵۰ فرم مرجع زیر منوی «اطلاعات پایه محصول سپرده»
- پشتیبانی از تاریخ اعتبار، نسخه کسب‌وکاری، وضعیت جاری، `CREATED_BY` و `RECORD_VERSION`

## ورودی موردنیاز مرحله عملیاتی Product Factory

- DDL کامل جدول‌های `DEPOSIT_PRODUCT*`
- Foreign Keyها و قواعد چرخه عمر محصول
- Base Data جداول مرجع
- Use Caseهای تأییدشده ایجاد، نسخه‌بندی، تأیید و انتشار محصول
