# F6-B — آزمایشگاه محاسبه نه‌روشی FEE3 برای تحلیلگر

**نسخه:** 2026-10-29 — **وضعیت:** توسعه Frontend و محاسبات آفلاین؛ اتصال نوشتن Oracle و تأیید بانکی عمداً انجام نشده است.

## آنچه واقعاً پیاده‌سازی شده است

در فرم «کارمزد ۳ / تعریف قلم جدید / گام آزمون و جمع‌بندی»، یک بخش «آزمایشگاه تحلیلگر — ۹ روش محاسبه» فراهم شده است. این بخش بدون ذخیره پیش‌نویس Oracle، نمونه‌سازی و محاسبه مبلغ پیش از مالیات انجام می‌دهد. کاربر می‌تواند ورودی‌ها را تغییر دهد، نتیجه عددی و شرح مراحل محاسبه را مشاهده کند، مبلغ مورد انتظار خود را وارد کند و یک **کاربرگ JSON قابل تحویل به تحلیلگر** شامل تعریف قاعده، ورودی‌ها، نتیجه، انتظار و وضعیت مقایسه صادر کند.

این‌ها **داده‌های ساختگی آموزشی** هستند، نه نرخ مصوب بانک. نمونه تنها با اقدام صریح تحلیلگر، روش و قواعد نسخه **محلی و پیش‌نویس** را جایگزین می‌کند و پیش از جایگزینی قواعد موجود، هشدار می‌دهد. محاسبات ثبت نسخه، ارسال Workflow، نشر تعرفه، مالیات، وصول وجه و Posting در این مسیر اجرا نمی‌شوند.

## کنترل‌های جداسازی و Fail-Closed

- فقط اقلام با پیشوند DEMO- یا F3-UAT-، فاقد شناسه Oracle، با نسخه DRAFT غیرفعال و ارز IRR محاسبه می‌شوند.
- روش FORMULA فقط سه فرمول عمومی مشخص را به‌شکل ریاضی و بدون eval اجرا می‌کند. فرمول ناشناخته، ابزار قرارداد یا عملیات تخصصی نیست.
- مدل‌های LOAN، GUARANTEE، LC و انواع مالی پیچیده مانند سود، خسارت یا قرض‌الحسنه نیازمند موتور تخصصی و شواهد قرارداد هستند و در آزمایشگاه عمومی مسدود می‌شوند.
- ACT/ACT و JALALI_ACT_ACT بدون قرارداد زمان‌شماری معتبر CAL2 عمداً مسدودند.
- تبدیل ارز، چندقاعده‌ای، بخشودگی، تعدیل، تخصیص و شرایط زمان‌بندی در این ابزار عمداً محاسبه نمی‌شوند.
- پس از هر تغییر در قواعد یا ورودی‌ها، نتیجه قبلی باطل می‌شود؛ نتیجه بدون محاسبه جدید قابل خروجی‌گرفتن نیست.
- خروجی دارای `NOT_A_BANK_APPROVAL` و `databaseWrites=0` است.

## وظیفه تحلیلگر

۱. در کارمزد ۳، گزینه «تعریف قلم جدید» را انتخاب و گام «آزمون و جمع‌بندی» را باز کند. برای نمونه‌سازی نیاز به پرکردن تمام شناسنامه یا ذخیره Oracle ندارد.

۲. روش موردنظر را از «آزمایشگاه تحلیلگر» انتخاب و «بارگذاری نمونه» را بزند؛ سپس «محاسبه مهندسی بدون ذخیره» را اجرا کند. برای MATRIX علاوه بر حالت حقیقی/موبایل، حقوقی/موبایل را امتحان کند که باید ۳۰٬۰۰۰ ریال شود.

۳. مبلغ مورد انتظار و یادداشت را ثبت، وضعیت PASS/FAIL را کنترل و دکمه «خروجی JSON سناریوی تحلیلگر» را بزند. فایل را در چرخه ارزیابی کارشناسی بررسی کند. نیازی به اجرای Python، Java یا API توسط تحلیلگر نیست.

## مرز تحویل

این نسخه تغییرات Frontend و ماژول ریاضی Local-only دارد. از آخرین سورس پروژه `core-banking-prototype-v0-2026-10-29-1542.zip` مشتق شده است. Oracle و Backend تغییر نمی‌کنند. Build Angular توسط INSTALL.cmd اجرا می‌شود و در صورت شکست، سورس اصلاح‌شده به حالت اولیه برمی‌گردد.
