## آزمون‌های اجراشده در محیط تهیه Patch

- کنترل نوع TypeScript با `tsc --strict` و اعلان‌های جداشده برای ماژول Angular: موفق؛ جایگزین `ng build` نیست.
- `python tools/fee3-ui/verify-parity-r4.py`: `FEE3_R4_PARITY_STATIC_OK=98`؛ چک‌های R4 برای UI R5 نیز حفظ شدند.
- `python tools/fee3-ui/verify-reference-r5.py`: `FEE3_R5_REFERENCE_UI_STATIC_PASS=132 FAIL=0`، شامل کنترل ۸۳ حلقه `@for` و شرط `track`.
- محاسبه مرجع PMT/IPMT: سود ماه اول تسهیلات ۱۰٬۰۰۰٬۰۰۰ ریالی، با نرخ سالانه ۱۸٪ و ۱۲ ماه = **۱۵۰٬۰۰۰ ریال**؛ آزمون PMT نیز با فرمول پایدار عددی انجام شد.
- آزمون با `EXCHANGE_IPMT_PERIOD` واقعی از کاتالوگ `FEE3_SEED_FORMULAS`: چهار ورودی `amount`, `rate`, `months`, `period` مطابق مرجع، مبلغ نمونه ۱۵۰٬۰۰۰ ریال.
- آزمون منفی: شماره دوره صفر یا بزرگ‌تر از مدت رد شد؛ فرمول ناشناخته و تبدیل ارز بدون منبع نرخ رسمی رد شدند.
- تمام فایل‌های تغییر یافته در محدوده FEE3، `tools/fee3-ui`، مستند QA و Manifest هستند. Backend/Oracle، FEE/FEE2 و ORG تغییر نکرده‌اند.

## محدودیت‌ها و شروط پذیرش

1. **Build واقعی Angular و Browser UAT هنوز در محیط تولید Patch انجام نشده‌اند.** پس از نصب لازم است `build-production.cmd` اجرا و همه خطاهای Angular بررسی شوند.
2. ماشین حالت Review و فعال‌سازی Demo فقط در حافظه نشست Frontend است و با Refresh صفحه از بین می‌رود. هیچ سرویس بانکی، Workflow یا Oracle فراخوانی نمی‌شود.
3. شبیه‌ساز عددی محدود تنها برای فرمول‌های پشتیبانی‌شده نتیجه می‌دهد. فرمول ناشناخته، روش ماتریسی چندبعدی، نرخ تبدیل ارز و رویدادهای نیازمند تاریخ معتبر به‌جای خروجی حدسی **خطای روشن** نشان می‌دهند. این موضوع به معنی آزمون کامل موتور محاسبه مرجع نیست.
4. در گام بررسی نهایی، دریافت نتیجه Workflow و تأیید رسمی تا اتصال Backend غیرفعال است. صرفاً قاب‌ها و توضیحات قابل مشاهده‌اند.
5. آزمون تطبیق *کامل تمام ترکیب‌های شرطی* ۷ مرحله با مرورگر HTML مرجع هنوز مستلزم UAT است؛ R5 تنها رفع مغایرت‌های مشخص‌شده تصاویر اخیر و Regression ساختاری است، نه ادعای تأیید نهایی همه ترکیب‌ها.

## دستور نصب روی R4+HF1

فقط ZIP افزایشی `FEE3-UI-R5-INCREMENTAL-FOR-R4-HF1.zip` را در ریشه پروژه جایگزین کنید. در صورتی که وضعیت R4/HF1 مشخص نیست، ZIP تجمعی `FEE3-UI-R5-CUMULATIVE-FOR-1627.zip` را روی پروژه مبنای 16:27 اعمال کنید.

```bat
cd /d D:\Projects\core-banking-prototype-v0
python tools\fee3-ui\verify-reference-r5.py
python tools\fee3-ui\verify-parity-r4.py
bin\stop.cmd
build-production.cmd
```

پس از Build موفق، مسیر `/#/fee3` یا منوی «کارمزد ۳» را بررسی و سناریوی IPMT دوره‌ای را از شناسنامه تا آزمون مبلغ اجرا کنید.
