# EDU 0.3.82 / FIX90 — فیلترهای تخصصی فرم‌های تحصیلات

## دامنه تغییر
برای شش فرم جدید Schema `EDU` فیلترهای سمت سرور اضافه شد. فیلترها به API عمومی Reference Data با قرارداد `filter.<apiField>=value` ارسال می‌شوند و Repository فقط فیلدهای معتبر Descriptor را به Query پارامتری Oracle تبدیل می‌کند.

## فیلترهای فرم‌ها
- مقاطع و مدارک تحصیلی: نظام آموزشی، قابل انتخاب، وضعیت فعال
- رشته‌ها و گرایش‌ها: نظام آموزشی، نوع گره، قابل انتخاب، وضعیت فعال
- مقاطع معتبر هر رشته: رشته تحصیلی، مقطع تحصیلی، منبع، وضعیت فعال
- دانشگاه‌ها و مؤسسات: نوع مؤسسه، نظام آموزشی، وضعیت مؤسسه، اعطاکننده مدرک، وضعیت فعال
- منابع داده آموزشی: نوع منبع، سال منبع، وضعیت فعال
- نگاشت منابع: منبع، نوع موجودیت، نوع نگاشت، وضعیت تطبیق، وضعیت فعال

## رفتار UI
- فیلترها در بخش مستقل «فیلترهای تخصصی» زیر جست‌وجوی عمومی نمایش داده می‌شوند.
- Lookupها عنوان فارسی نشان می‌دهند و ID عددی فقط به API ارسال می‌شود.
- تغییر فیلتر صفحه را به صفحه اول برمی‌گرداند.
- دکمه «پاک کردن فیلترها» همه فیلترهای تخصصی را حذف می‌کند.
- جست‌وجوی متن، مرتب‌سازی و Pagination موجود حفظ شده است.

## تغییر منوی عمومی
مطابق درخواست قبلی، سه گزینه مرتبط با واژگان در گروه جدید «واژگان و اصطلاحات» قرار گرفتند:
- واژه‌نامه رومن‌نویسی نام‌ها
- واژه‌نامه پیشوند و پسوند نام
- تبدیل نام فارسی به انگلیسی

## نکته Build
در محیط تولید artifact، Maven و `node_modules` محلی در دسترس نبود؛ بنابراین Build اجرایی انجام نشد. تغییرات Source و قرارداد Frontend/Backend به‌صورت Static بررسی شدند.
