# گزارش کنترل‌های FEE UX R3-A

مبنای کد: `core-banking-prototype-v0-2026-10-11-2153.zip` با دو Patch مستقل R2.2 و R2.3.

- هر پنج جدول دارای FK به `FEE_DEFINITION_VERSION_ID` هستند.
- `FEE_CHARGE_STAGE` علاوه بر نسخه، FK اجباری به `FEE_CALCULATION_RULE` دارد. R3-A برای جلوگیری از ایجاد رابطه اشتباه، ثبت/ویرایش مرحله را در محیط جدید غیرفعال کرده است.
- از API موجود `/api/v1/fees/admin` و فیلتر موجود سمت سرور استفاده می‌شود. تغییر Backend/Oracle وجود ندارد.
- فقط دو فایل Workspace اختصاصی FEE اصلاح، سه فایل جدید FEE اضافه و Route فعلی FEE به‌صورت هدفمند Guard می‌شود؛ محتوا/Routeهای Product Builder و FEE2 بازنویسی نمی‌شوند.
- کنترل‌های نصب‌کننده شامل قبل/بعد SHA، تشخیص تعارض، نصب تکراری و بازگشت امن هستند.
- کامپایل کامل Angular و اجرای Oracle/مرورگر خارج از محیط آزمون محلی است؛ دستور و سناریوی UAT در راهنما آمده‌اند.
