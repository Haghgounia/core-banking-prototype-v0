# CIF 0.3.22 Fix 14 — Financial / Employment UI QA

## Scope

این اصلاح روی فرم عملیاتی `اطلاعات مالی و شغلی / فعالیت اقتصادی` متمرکز است و Schema عملیاتی موجود را حفظ می‌کند.

## تصمیم‌های طراحی

| مورد | تصمیم اجراشده | Persistence |
|---|---|---|
| فعالیت اقتصادی | نمایش عنوان فارسی از `REF_ISIC_ACTIVITY` | ذخیره `ISIC_CODE` |
| تعداد اعضای خانوار | ورودی عدد صحیح مثبت | تبدیل به String و ذخیره در `FAMILY_RANGE VARCHAR2(20)` |
| بازه کارکنان کارفرما | ComboBox با بازه‌های عملیاتی پیش‌فرض | ذخیره کد بازه در `EMPLOYEE_RANGE` |
| سطح توان مالی | ComboBox عنوان‌محور | ذخیره `FINANCIAL_CAPACITY_CODE` |
| هدف رابطه مالی | ComboBox عنوان‌محور | ذخیره `FINANCIAL_RELATION_PURPOSE_CODE` |
| کشورهای مبدأ / مقصد وجوه | Multi-select از `GEO.COUNTRIES` | ذخیره کدهای ISO در `FUNDS_COUNTRIES_TEXT` |
| مبالغ | کنترل مشترک با جداکننده هزارگان و نرمال‌سازی ارقام فارسی/عربی | ارسال مقدار عددی بدون جداکننده |

## بازه‌های کارکنان کارفرما

- ۱ تا ۵ نفر (`1-5`)
- ۶ تا ۱۰ نفر (`6-10`)
- ۱۱ تا ۵۰ نفر (`11-50`)
- ۵۱ تا ۱۰۰ نفر (`51-100`)
- ۱۰۱ تا ۵۰۰ نفر (`101-500`)
- بیش از ۵۰۰ نفر (`501+`)

## سطح توان مالی

- پایین (`LOW`)
- متوسط (`MEDIUM`)
- بالا (`HIGH`)
- بسیار بالا (`VERY_HIGH`)

## هدف رابطه مالی

- خدمات روزمره بانکی (`DAILY_BANKING`)
- پس‌انداز (`SAVING`)
- سرمایه‌گذاری (`INVESTMENT`)
- فعالیت تجاری / کسب‌وکار (`BUSINESS`)
- دریافت تسهیلات و تأمین مالی (`FINANCING`)

برای سطح توان مالی، هدف رابطه مالی و بازه کارکنان، در مدل فیزیکی تحویلی REF مستقل وجود ندارد؛ بنابراین برای جلوگیری از ساخت Reference Data مصنوعی، Vocabulary کنترل‌شده در UI نگهداری شده و Code موجود در جدول عملیاتی ذخیره می‌شود.

## مبالغ دارای جداکننده هزارگان

- درآمد ماهانه اشتغال
- درآمد ماهانه خالص / درآمد عملیاتی ماهانه
- سایر درآمد ماهانه / سایر درآمد عملیاتی
- درآمد سالانه
- گردش ماهانه مورد انتظار
- ارزش کل دارایی‌ها
- مجموع بدهی‌ها
- ارزش املاک
- ارزش سرمایه‌گذاری‌ها
- مجموع اقساط ماهانه
- خالص ثروت تقریبی
- مبلغ ماهانه منبع درآمد
- ارزش / مانده دارایی یا تعهد

کنترل `FormattedAmountInputComponent` ارقام فارسی، عربی و انگلیسی و جداکننده‌های `,` و `٬` را نرمال می‌کند و حداکثر دو رقم اعشار را می‌پذیرد.

## اصلاح داده مرجع ISIC

در Seed قبلی چهار رکورد نمونه `REF_ISIC_ACTIVITY` عنوان فارسی/انگلیسی برابر خود کد داشتند. Fix 14 این عناوین را اصلاح می‌کند و Migration زیر برای دیتابیس‌های موجود اضافه شده است:

`database/oracle/cif/migrations/0.3.22-fix14-financial-employment-ui.sql`

## Validation / Submit State

پس از Save موفق، `FormGroupDirective` فرم‌های اشتغال، پروفایل مالی، منبع درآمد، دارایی/تعهد و مجوز Reset می‌شود تا وضعیت `submitted` باعث نمایش اشتباه فیلدهای Required به رنگ خطا نشود.

## QA انجام‌شده در محیط بسته

- Parse موفق فایل `party-reference-model.json`.
- بررسی Syntax دو فایل TypeScript تغییرکرده با TypeScript transpiler.
- بررسی توازن Tagهای اصلی Angular Material در Template.
- بررسی وجود تمام Form Controlهای تغییرکرده در Template و FormGroup.
- بررسی حذف Handlerهای قدیمی مبلغ و عناوین خام «کد سطح توان مالی / کد هدف رابطه مالی».
- Build کامل Angular و Maven در این محیط قابل تکمیل نبود، چون وابستگی‌های npm/Maven داخل ZIP موجود نبود و دسترسی شبکه Container برای دریافت Registry/Repository با خطای DNS قطع بود.
