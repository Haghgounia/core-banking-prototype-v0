# رفع خطای نبود آزمون PB-R19 در Build

## تشخیص

فایل `ProductGovernanceStopOnlyR19Test.java` در آرشیو کامل R19/R20-HF1 وجود دارد؛ اما در Patch افزایشی R20-HF1 نیست، زیرا مبنای Patch نصب کامل R19 است. این ZIP فقط فایل آزمون جاافتاده را بازمی‌گرداند و ابزار تشخیص اختیاری اضافه می‌کند. هیچ فایل قبلی Java/Angular/Oracle بازنویسی نمی‌شود.

## اجرای اصلاحیه

1. از پروژه فعلی Backup تهیه کنید.
2. ZIP اصلاحیه را **داخل ریشه پروژه** `D:\Projects\core-banking-prototype-v0` استخراج کنید تا پوشه‌های `backend`، `tools`، `docs` ادغام شوند.
3. در CMD اجرا کنید:

```bat
cd /d D:\Projects\core-banking-prototype-v0
node tools\diagnose-pb-r19-baseline.mjs
node tools\verify-pb-r19.mjs
build-production.cmd
```

اگر Diagnostic هشدار داد، مبنای پروژه شما افزون بر آزمون جاافتاده، به احتمال زیاد بخشی از تغییرات R19 را هم ندارد. فایل‌های اصلی را بدون بررسی و Merge از یک ZIP قدیمی کپی نکنید.
