# QA — FEE R3-B

- کارایی نسخه انتخاب‌شده: فیلتر `FEE_DEFINITION_VERSION_ID` برای پنج جدول حفظ شده است.
- برای مرحله اخذ، لیست قواعد و مؤلفه‌ها بر اساس همان نسخه پرس‌وجو می‌شوند.
- Backend عمومی FEE در Create و Update نسخه قاعده و مؤلفه را بررسی می‌کند، و با قفل تراکنشی و بررسی جابه‌جایی والد از ناسازگاری ناشی از تغییر هم‌زمان پیشگیری می‌کند.
- فرم فنی قدیمی از همان API استفاده می‌کند و مشمول کنترل است.
- قابلیت بازگشت/نصب مجدد و تشخیص تعارض از طریق SHA-256 برای فایل‌های FEE برقرار است.
- Product Builder/FEE2/DDL/Routes/AppShell در فهرست اهداف Patch نیستند.
- تأیید نهایی کامپایل Spring/Angular و Oracle runtime در محیط Windows مورد نیاز است.
