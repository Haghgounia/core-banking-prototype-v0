# CAL/CAL2 0.3.44 — FIX55: ساده‌سازی عنوان تقویم‌ها

## هدف

در رابط کاربری، دو مدل تقویم از این نسخه صرفاً با عناوین «تقویم یک» و «تقویم دو» نمایش داده می‌شوند. نام فنی Schemaها بدون تغییر است:

- `CAL` → تقویم یک
- `CAL2` → تقویم دو

## تغییرات UI

عبارت‌های نمایشی «تقویم سازمانی»، «تقویم BIAN» و «چهارصدساله» از فرم‌های فعال تقویم حذف شدند. این تغییر شامل Hub اطلاعات پایه، Breadcrumbها، صفحه فهرست فرم‌ها، فرم‌های رکورد، صفحه Import و System Specification است.

گروه‌های Dataset در هر دو ماژول با عنوان «Dataset تقویم» نمایش داده می‌شوند. نام فایل‌ها، Schemaها، Routeها، Endpointها، جدول‌ها و ساختار Oracle تغییر نکرده‌اند.

## کنترل رگرسیون

Guard جدید `tools/verify-calendar-display-labels.mjs` موارد زیر را کنترل می‌کند:

1. عنوان کارت CAL در Hub دقیقاً «تقویم یک» باشد.
2. عنوان کارت CAL2 در Hub دقیقاً «تقویم دو» باشد.
3. عنوان اصلی منوی CAL «تقویم یک» باشد.
4. عنوان اصلی منوی CAL2 «تقویم دو» باشد.
5. عبارت‌های قدیمی در فرم‌های زنده و Registryهای Backend باقی نمانده باشند.

## Database

هیچ DDL، Migration یا تغییر داده‌ای لازم نیست. Schemaهای `CAL` و `CAL2` و تمام FK/PK/Indexها بدون تغییر هستند.
