# وضعیت نقشه راه ثابت وثایق پس از تحویل R6A — ۲۰۲۶/۱۱/۰۴

| فاز | وضعیت صادقانه |
|---|---|
| R0 | خط مبنا و مصوبات نقشه راه تثبیت‌شده |
| R1 | پیاده‌سازی داده مرجع/حاکمیت؛ Runtime و تصمیم بانک باز |
| R2 | شناسنامه/معرفی/Preflight؛ ثبت قطعی بسته |
| R3 | ضامن/بیمه/ارزیابی؛ نهایی‌سازی بسته |
| R4 | R4A–R4D دارای Build موفق اعلام‌شده؛ تخصیص مالی بسته |
| R5 | R5A و R5C دارای Build موفق اعلام‌شده (شامل سورس R5B)؛ رفع تخصیص و آزادسازی مالی بسته |
| **R6** | **R6A: ساخت میزکار UAT، نقشه ۱۵ نما و ناوبری شناسنامه؛ Build Windows در انتظار؛ ثبت Route مشترک و UAT تحلیلگر باز** |
| R7 | یکپارچه‌سازی واقعی و آمادگی عملیاتی انجام نشده |

**کنترل تغییر:** شناسه‌ها و نام فازهای `CLT-ROADMAP-R1.0` ثابت مانده‌اند. این نسخه نام فاز جدیدی تعریف نمی‌کند و Oracle Write را فعال نکرده است.

**مانع جدید R6 — Integration:** عدم ثبت Routeهای Angular Collateral در `app.routes.ts`. بدون مجوز اصلاح فایل مشترک، UAT در UI اصلی مسدود است؛ فایل آفلاین فقط امکان ثبت شواهد دستی می‌دهد.

**شکاف‌های باز:** G-01..G-22 مطابق اسناد تحویل‌های قبلی، به‌ویژه G-02، G-07، G-09، G-14، G-18، G-19، G-20، G-21 و G-22. نتیجه فنی `Build PASS` معادل رفع آن‌ها نیست.

**گام بعد درون R6:** تعیین تکلیف رسمی Route/منو، اتصال واقعی UI با Runtime تست، تکمیل گزارش‌های خواندنی و اجرای UAT تحلیلگر؛ سپس ورود کنترل‌شده به R7، بدون بستن زودهنگام R6.
