# خط مبنای وضعیت ثابت Collateral — گزارش R3C

مرجع اصلی و تغییرناپذیر بدون موافقت صریح ذی‌نفع: **CLT-ROADMAP-R1.0** (R0 تا R7). این گزارش تنها یک Snapshot وضعیت توسعه است و فازها را تغییر نام نمی‌دهد.

| فاز ثابت | وضعیت واقعی تا 2026-11-03 | شواهد و مانع |
|---|---|---|
| R0 — تحلیل و تثبیت خط مبنا | تحلیل ایستا انجام‌شده | اسناد و شکاف‌نامه R1.0 |
| R1 — اطلاعات پایه و حاکمیت قواعد | R1A/R1B در سورس نصب/Build شده‌اند، خاتمه فاز تأیید نشده | آزمون عملیاتی Maker/Checker و Oracle/Audit باز |
| R2 — شناسنامه، معرفی و جست‌وجو | R2A تا R2E توسعه یافته و R2E Build تأییدشده توسط کاربر | ثبت قطعی غیرفعال؛ G-01/G-03/G-12/G-14/G-16/G-17 باز |
| R3 — ضامن، بیمه و ارزیابی | R3A و R3B Build موفق توسط کاربر؛ R3C سورس/Installer تحویلی | G-04/G-05/G-06/G-07/G-09/G-10/G-11/G-18 باز؛ آزمون Runtime Oracle هنوز لازم |
| R4 — ظرفیت و تخصیص بین‌دامنه‌ای | شروع نشده | نیازمند سیاست ارزش معتبر، مصرف‌کنندگان، عدم ابطال تخصیص قبلی، Idempotency |
| R5 — رفع تخصیص، آزادسازی و سوابق | شروع نشده | دامنه‌های مصرف‌کننده و lifecycle |
| R6 — تکمیل رابط کاربری و UAT جامع | شروع نشده | UAT بر اساس ۱۵ نما/۱۰ سناریوی مرجع |
| R7 — یکپارچه‌سازی، امنیت و آمادگی عملیاتی | شروع نشده | IAM/JWT، Oracle، ادغام، امنیت و کارایی |

**R3C**: سوابق ارزیابی، کنترل زمان ثبت‌شده و فرم اعتبارسنجی/درخواست DRAFT اختیاری آماده شده؛ ثبت `FINAL` در Oracle، تمدید/جایگزینی قطعی و اعلام آمادگی تخصیص همچنان غیرفعال‌اند. هیچ رقم، مبلغ، Haircut یا واحد دوره‌ای بانکی ساخته نشده است.

**مرجع گام بعدی:** تعیین تکلیف G-07/G-18 و اعتبارسنجی Runtime R3C، سپس ادامه R4 در چارچوب نقشه راه ثابت. تغییرات IAM/CIF/DPS2 مجزا هستند و نیازمند ادغام حفظ شواهد هنگام R7 خواهند بود.
