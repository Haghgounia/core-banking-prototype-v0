# وضعیت نقشه راه ثابت وثایق — CLT-ROADMAP-R1.0 / R5A / 2026-11-04

**قاعده نسخه‌بندی:** نام و دامنه R0 تا R7 بر اساس سند رسمی بدون تغییر باقی می‌ماند. R5A یک تحویل داخلی فاز R5 است، نه فاز جدید.

| فاز مصوب | وضعیت مبتنی بر شواهد | بازمانده |
|---|---|---|
| R0 — تحلیل و تثبیت خط مبنا | مستندات و Gap Register تهیه شده | کنترل تغییرات و تطبیق نهایی با Oracle زنده |
| R1 — اطلاعات پایه و حاکمیت قواعد | کد و UI توسعه یافته | سیاست‌ها، حساب Read، UAT، تأیید Oracle |
| R2 — شناسنامه، معرفی و جست‌وجو | R2A–R2E تحویل سورس | ثبت قطعی، شماره انتظامی، تصمیم‌های G-01/G-03/G-14/G-17 |
| R3 — ضامن، بیمه و ارزیابی | R3A–R3C با Build گزارش‌شده موفق | قواعد عملیاتی و Final Writes غیرفعال، G-07/G-18 |
| R4 — ظرفیت و تخصیص بین‌دامنه‌ای | R4A–R4D با Build واقعی کاربر موفق | DDL/Writer Idempotency، قفل واقعی Oracle، مصرف‌کنندگان و تراکنش مالی |
| **R5 — رفع تخصیص، آزادسازی و سوابق** | **R5A سورس آماده Build: نمایش تاریخچه + Preflight بدون Write** | R5B آزادسازی گردش تخصیص، R5C Final Release و سوابق/معرفی مجدد |
| R6 — تکمیل رابط کاربری و UAT جامع | UI تدریجی تا R5A | تکمیل ۱۵ نمای مرجع، سناریوهای کسب‌وکار و UAT جامع |
| R7 — یکپارچه‌سازی، امنیت و آمادگی عملیاتی | کنترل‌های Source Security در مراحل قبلی | Oracle/IdP/Consumer Runtime، تست بار/مهاجرت و آمادگی انتشار |

## شواهد آخرین Baseline
- تأیید واقعی Windows برای R4D در خروجی کاربر: `CLT_R4D_FULL_BUILD_AND_JAR=PASS`, `NG8102=0`, `ORACLE_CONCURRENCY_EXECUTION=NONE`, `ALLOCATION_WRITES=DISABLED`.
- R5A به‌عنوان Source Candidate ساخته و آزمون Pure Java/Parser/Installer در محیط توسعه اجرا شده؛ **Build کامل Windows هنوز گزارش نشده است.**
- هیچ DDL/DML Oracle یا تغییر مشترک IAM/CIF/DPS2 در R5A وجود ندارد.

## اولویت مسیر بعد
۱. تأیید Build و اجرای UAT خواندنی R5A. ۲. R5B: قرارداد عملیات واقعی رفع تخصیص، Idempotency و Audit به‌صورت غیرفعال تا تأیید DBA؛ بدون قیاس با Final Release. ۳. در مسیر موازی، بستن G-02/G-08/G-09/G-13/G-16/G-19/G-20 و پیش‌نیازهای فازهای R2/R3/R4.
