# وضعیت نسخه‌دار نقشه راه CLT پس از R5C

**مرجع ثابت:** `CLT-ROADMAP-R1.0` — **وضعیت در 2026-11-04** — **نسخه محصول:** `0.11.0` — **Delivery:** R5C.1.0

| فاز ثابت | نام مصوب | وضع فعلی |
|---|---|---|
| R0 | تحلیل و تثبیت خط مبنا | اسناد خط مبنا و شکاف‌ها تهیه شده‌اند |
| R1 | اطلاعات پایه و حاکمیت قواعد | کد و UI توسعه‌یافته؛ تأیید/حاکمیت عملیاتی باز |
| R2 | شناسنامه، معرفی و جست‌وجو | R2A–R2E توسعه یافته؛ شماره انتظامی و ثبت قطعی غیرفعال |
| R3 | ضامن، بیمه و ارزیابی | R3A–R3C توسعه یافته؛ ثبت نهایی و سیاست‌های نوع‌محور باز |
| R4 | ظرفیت و تخصیص بین‌دامنه‌ای | R4A–R4D Build تأییدشده توسط کاربر؛ تخصیص اتمیک مالی غیرفعال |
| R5 | رفع تخصیص، آزادسازی و سوابق | R5A Build تأییدشده؛ R5B تحویل‌شده و Build کاربر در این گفتگو هنوز گزارش نشده؛ **R5C سورس تحویل‌شده** |
| R6 | تکمیل رابط کاربری و UAT جامع | آغاز رسمی UAT جامع اعلام نشده؛ UI تدریجی در R1–R5 ایجاد شده است |
| R7 | یکپارچه‌سازی، امنیت و آمادگی عملیاتی | Oracle Runtime/JWT/دیسپچ دامین‌ها و آزمون عملیاتی باز |

## وضعیت دقیق R5C

**انجام‌شده:** وضعیت آزادسازی، شواهد تخصیص/تراکنش، تاریخچه وضعیت، Preview بدون ثبت، کنترل JWT/Branch، نمایش Angular، آزمون مستقل قواعد و بسته نصب با کنترل SHA.

**باقی‌مانده:** استعلام حقوقی معتبر، نگاشت قطعی وضعیت RELEASED، اتمیک‌بودن رفع تخصیص/آزادسازی در Oracle، آزمون بین‌دامنه‌ای با DPS2 و بدهکار، Rollback، UAT تحلیلگر و استفاده عملیاتی.

**موانع کلیدی:** G-09، G-13، G-19، G-20، **G-21** و **G-22**. هیچ سیاست یا جدول جدیدی بدون تأیید بانک/DBA اعمال نشده است.

**گام بعد:** ورود به R6 برای تکمیل ۱۵ نمای UI مرجع و سناریوهای جامع UAT، همراه با مسیر تعیین تکلیف موازی G-21/G-22؛ تغییر نام فازهای R0–R7 ممنوع است.

**مرجع رفتار:** `Collateral_UI_Final_Offline_V1.42_FA.html`، Business/System Use Cases، API/DB Specification. **مرجع نصب:** سورس واقعی `Core Banking Prototype`.
