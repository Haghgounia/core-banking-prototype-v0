# وضعیت رسمی نقشه راه Collateral — checkpoint R4D

تاریخ: 2026-11-03. نقشه راه `CLT-ROADMAP-R1.0` و نام فازها تغییر نکرده‌اند. Baseline فنی: Core Banking Prototype 0.11.0.

| فاز مصوب | وضعیت در checkpoint R4D |
|---|---|
| R0 — تحلیل و تثبیت خط مبنا | بررسی اسناد و مدل تکمیل |
| R1 — اطلاعات پایه و حاکمیت قواعد | R1A/R1B در سورس؛ DBA/Policy/Runtime UAT باز |
| R2 — شناسنامه، معرفی و جست‌وجو | R2A تا R2E؛ ثبت قطعی، شماره انتظامی و هویت یکتای دارایی بسته |
| R3 — ضامن، بیمه و ارزیابی | R3A تا R3C؛ درخواست‌ها و Readها پیاده، نهایی‌سازی‌های واقعی بسته |
| R4 — ظرفیت و تخصیص بین‌دامنه‌ای | R4A محاسبه، R4B Preflight، R4C دفتر درخواست، **R4D Probe قفل سطر با داده درون تراکنش**؛ هنوز **تخصیص عملیاتی ندارد** |
| R5 — رفع تخصیص، آزادسازی و سوابق | آغاز نشده |
| R6 — تکمیل رابط کاربری و UAT جامع | آغاز رسمی نشده |
| R7 — یکپارچه‌سازی، امنیت و آمادگی عملیاتی | آغاز رسمی نشده |

**این checkpoint درباره نسخه تحویلی R4D است؛ موفقیت نصب و Build واقعی تا دریافت لاگ Windows قابل ادعا نیست.** قفل R4D هیچ ظرفیت مالی رزرو نمی‌کند و API صدور تخصیص ندارد. G-02/G-09/G-13/G-16 و وابستگی‌های R2/R3 همچنان بازند.

### اقدام بعدی

مسیر توسعه: R5 در حوزه خواندن سوابق و طراحی رفع تخصیص/آزادسازی با Fail-Closed. مسیر معماری/DBA: تعیین تکلیف تراکنش تخصیص واقعی، قرارداد قفل سراسری، Idempotency و سیاست‌ها. هیچ فاز ثابتی بازتعریف نمی‌شود.
