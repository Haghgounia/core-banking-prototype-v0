# CLT-ROADMAP-R1.0 — وضعیت پس از R4C

نقشه راه مصوب R0 تا R7 تغییر نکرده است. این سند فقط گزارش وضعیت تحویل را به‌روزرسانی می‌کند.

| فاز | وضعیت تأییدشده | بازمانده |
|---|---|---|
| R0 | تکمیل بررسی و خط مبنا | تغییر خط مبنا فقط با مصوبه |
| R1 | R1A/R1B در سورس؛ Buildهای پروژه موفق گزارش شده | Audit سیاست‌های رسمی، IAM/Oracle Runtime/UAT |
| R2 | R2A-R2E در سورس؛ Build تا R2E گزارش شده | ثبت قطعی، هویت دارایی، شماره انتظامی، اقلام شمارشی و اصلاحیه |
| R3 | R3A-R3C Build موفق گزارش شده | تصویب چرخه ضامن/بیمه/ارزیابی و عملیات نهایی |
| R4 | R4A و R4B Build موفق گزارش شده؛ R4C به‌صورت سورس مرحله‌ای تحویل | DBA approval، JWT/Oracle Runtime، قفل ظرفیت، تخصیص مالی واقعی |
| R5 | شروع نشده | رفع تخصیص، آزادسازی، سوابق و معرفی مجدد |
| R6 | UAT جامع شروع رسمی نشده | ۱۵ نمای UI و ۱۰ سناریوی UAT |
| R7 | تأیید عملیاتی شروع نشده | IAM، Oracle، Adapter مصرف‌کننده، تست E2E و انتشار |

R4C فقط **دفتر درخواست مرحله‌ای** را با Idempotency و Audit در سورس اضافه می‌کند؛ Write پیش‌فرض خاموش و تخصیص مالی همواره غیرفعال است. این تحویل به معنای بسته‌شدن R4 نیست.

**گام بعدی:** تکمیل تصمیم‌های مانع R2/R3/R4 و طراحی واحد اتمیک Allocation در R4؛ شروع قابلیت‌های مستقل R5 بدون ادعای عملیات مالی مجاز است.
