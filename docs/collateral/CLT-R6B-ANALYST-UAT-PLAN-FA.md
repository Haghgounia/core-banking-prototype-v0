# CLT-R6B | دستورکار عملیاتی UAT تحلیلگر بدون پیش‌فرض تکمیل IAM

۱. نصب نسخه R6B و دریافت `CLT_R6B_PROJECT_BUILD_AND_JAR=PASS`؛ این صرفاً پذیرش Build است.

۲. از منوی جدید **مدیریت وثایق** به «میزکار UAT تحلیلگر» وارد شوید. در وضعیت آغازین هر ۱۰ سناریو باید `NOT_RUN` باشد. اگر نیازمند JWT/Oracle است و پیش‌شرط فراهم نیست، وضعیت `BLOCKED` و علت را ثبت کنید، نه `PASS`.

۳. برای ارزیابی ظاهر و ناوبری، URLهای `/collateral`، `/collateral/lookup`، `/collateral/introduction`، `/collateral/reference-data`، `/collateral/reports` و `/collateral/uat` را در محیط ۱۳۶۶ پیکسل و موبایل بررسی کنید. صفحه نیازمند API در نبود IAM باید خطای روشن نشان دهد و داده جعلی نداشته باشد.

۴. در صورت فراهم‌شدن دسترسی آزمون، سناریوهای `UAT-01` تا `UAT-10` را مطابق ماتریس `CLT-R6A-TRACEABILITY-MATRIX-FA.md` اجرا کنید. سناریوهای مربوط به Write بانکیِ غیرفعال باید `BLOCKED` بمانند.

۵. خروجی JSON را در مسیر امن پروژه نگه دارید. امکان **بازیابی JSON** در میزکار وجود دارد؛ هر بار تنها ده شناسه مجاز بازگردانی می‌شوند. اطلاعات مشتری، شناسه ملی، شماره حساب و داده‌های محرمانه را در یادداشت‌ها وارد نکنید.
