**مرجع برنامه:** `CLT-ROADMAP-R1.0` (بدون بازتعریف فازها)  
**تاریخ:** ۱۴۰۵/۰۸/۱۳ (۲۰۲۶-۱۱-۰۴)  
**منابع داخلی:** `Collateral_UI_Final_Offline_V1.42_FA.html`، `Collateral_UI_Specification_FA.html`، `Collateral_Business_Use_Cases_FA.html`، `Collateral_System_Use_Cases_FA.html`، سورس تا R5C.

## ۵. پیش‌شرط‌های باز برای پذیرش R6 کامل

1. **Route حیاتی:** `frontend/src/app/app.routes.ts` فعلاً نه `/collateral` و نه `/collateral/reference-data` را ثبت نکرده است. R6A فایل‌های مشترک را تغییر نمی‌دهد. تا یکپارچه‌سازی دارای مجوز، صفحه‌های Angular عملاً ورودی قابل اتکا ندارند.
2. **Runtime:** JWT شعبه/Scope، Oracle Read-only و مسیرهای API در محیط تست با داده غیرمحرمانه نیازمند آزمون واقعی هستند.
3. **R2–R5:** ثبت قطعی، Maker/Checker، تخصیص واقعی، رفع تخصیص واقعی و آزادسازی نهایی غیرفعال می‌مانند.
4. **پوشش گزارش:** Viewهای `dashboard`, `recentEvents`, `hqDashboard` و ظرفیت تجمیعی نیازمند API، مجوز و داده حقیقی‌اند.
5. **موارد کاربرد:** تکمیل ردیابی BUC/SUC باید با شواهد اجرای سناریو و پیوند به APIهای واقعی تکمیل شود؛ فهرست صرفاً نخستین لایه Traceability است.
6. **دسترس‌پذیری:** RTL، صفحه ۱۳۶۶ و صفحه‌کلید/Focus باید با مرورگر واقعی بررسی شوند.

## ۶. محدوده واقعی بسته R6A

- ناوبری درون شناسنامه به ۹ بخش (Summary، Sponsor، Insurance، Valuation، Capacity، Allocation، Unallocation، Release، History) تبدیل شده؛ از بارگذاری یک‌باره هفت پنل جلوگیری می‌شود.
- میزکار UAT در کد Angular با ۱۰ سناریوی مرجع، پیش‌شرط، اقدام، نتیجه، دلیل و خروجی JSON نشستی افزوده شده است.
- نقشه پوشش ۱۵ نما با وضعیت صریح «کامپوننت موجود/جزئی/شکاف» در میزکار نمایش داده می‌شود.
- نسخه HTML آفلاین برای ثبت دستی نتایج بدون اتصال به بانک ارائه شده است.
- Route مشترک، Oracle، JWT، IAM، CIF و DPS2 دست‌نخورده‌اند؛ بنابراین **اتصال نهایی Angular به Route باز است**.
