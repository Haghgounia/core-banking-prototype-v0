## مرجع و محدوده
مبنا: `core-banking-prototype-v0-2026-11-08-0932` به‌علاوه اصلاحات R2. معیار بصری: الگوی اطلاعات پایه `/#/reference-data/currencies` (فرم ارزها در ماژول داده مرجع). داده `CLT.REF_CURRENCY` با `GEO.CURRENCIES` ادغام نشده است.

## تغییرات قابل تأیید از سورس
- ۱۷ جدول اطلاعات پایه از یک Workspace مشترک با Angular Material Table، Sort، Paginator، فیلتر وضعیت، جست‌وجوی سراسری سرور، عملیات آیکونی و فرم Create/Update استفاده می‌کنند.
- فیلدهای STATUS و پرچم‌های CHAR(1) و عدد، انتخابگر FK سه‌گانه و کد نوع داده ویژگی از Metadata نوع‌گذاری شده‌اند؛ طول رشته در فرم محدود می‌شود و اعتبارسنجی Backend حفظ شده است.
- برای جدول رابطه نوع وثیقه/ویژگی، فیلترهای مبتنی بر مرجع و query پارامتری اضافه شده‌اند.
- نام موتور پایگاه داده از Header و دکمه‌های اصلی CRUD حذف شده؛ مشخصات فنی فقط در پنل بازشونده ویژه پشتیبانی است.
- قالب‌های ۱۴ جزء وثایق از توکن‌های UI مشترک استفاده می‌کنند. دو Diagnostics فنی همچنان استثناء هستند. پنل‌های عملیاتی هنوز دارای برخی کنترل‌های بومی خود هستند؛ تغییر کامل آن‌ها به Material در این نسخه **انجام نشده** است.
- در معرفی وثیقه، کد ارز آزاد به انتخاب از داده‌های فعال `CLT.REF_CURRENCY` تبدیل شد؛ ثبت قطعی/تخصیص/آزادسازی بدون قرارداد مصوب فعال نشده است.
- متدهای CRUD قبلی با DataSource مشترک و کنترل نسخه `RECORD_VERSION` دست‌نخورده باقی مانده‌اند. نصب هیچ SQL اجرا نمی‌کند.
