# وضعیت نسخه‌دار نقشه راه CLT-ROADMAP-R1.0 — تحویل R3A

تاریخ مبنا: 2026-11-03 | نسخه محصول: 0.11.0 | Roadmap ID ثابت: CLT-ROADMAP-R1.0

| فاز ثابت | وضعیت واقعی |
|---|---|
| R0 — تحلیل و تثبیت خط مبنا | بررسی ایستا و دفتر شکاف‌ها تهیه‌شده |
| R1 — اطلاعات پایه و حاکمیت قواعد | R1A/R1B در سورس؛ تأیید عملیاتی Oracle/Maker-Checker هنوز باز |
| R2 — شناسنامه، معرفی و جست‌وجو | R2A تا R2E با Build موفقِ گزارش‌شده توسط کاربر؛ ثبت قطعی غیرفعال و G-03/G-14/G-17 باز |
| **R3 — ضامن، بیمه و ارزیابی** | **R3A ضامنین: برش خواندن/اعتبارسنجی و درخواست مرحله‌ای، تحت آزمون Build/Runtime**؛ بیمه و ارزیابی باقی است |
| R4 — ظرفیت و تخصیص بین‌دامنه‌ای | شروع نشده |
| R5 — رفع تخصیص، آزادسازی و سوابق | شروع نشده |
| R6 — تکمیل رابط کاربری و UAT جامع | شروع نشده؛ UI به‌صورت افزایشی پیش می‌رود |
| R7 — یکپارچه‌سازی، امنیت و آمادگی عملیاتی | شروع نشده؛ Oracle قطعی پس از مصوبه |

### شواهد و موانع
- R3A: کلاس‌های پایدار و پنل Angular مستقل، `BUC-06/SUC-07/SUC-08`؛ آزمون Pure-JDK و TypeScript Parser و نصب آزمایشی در گزارش QA تحویل ثبت می‌شود.
- `G-05`: وضعیت و لغو ضامن در جدول فیزیکی نیست؛ اعتبار برای تخصیص تأیید نمی‌شود.
- `G-11`: حداقل تعداد ضامن در DDL `COLLATERAL_TYPE` موجود نیست؛ عدد اختراعی ممنوع.
- باز بودن R2 مانع توسعه مستقل R3 نمی‌شود، اما مانع فعال‌سازی جریان ثبت قطعی از طریق R3 نمی‌شود.
- IAM/CIF/DPS2 و پیکربندی مشترک بدون دست‌کاری نگه داشته می‌شوند؛ فقط کد مختص Collateral ارتقا می‌یابد.
