# وضعیت نسخه‌دار نقشه راه وثایق — R2B

**مرجع ثابت:** `CLT-ROADMAP-R1.0`؛ فازهای R0، R1، R2، R3، R4، R5، R6، R7 بدون تغییر نام و دامنه معتبرند.

| فاز | وضعیت واقعی | شاهد/مانع |
|---|---|---|
| R0 | تحلیل و نقشه راه تدوین شده | اسناد ۱۲گانه مرجع؛ وضعیت تصمیم‌گیری XMI مستقل از نقشه راه |
| R1A | Source + Build در Windows طبق خروجی گزارش‌شده | ۱۷ جدول پایه؛ Oracle read و IAM واقعی هنوز Gate باز |
| R1B | Source + Build در Windows طبق خروجی گزارش‌شده | G-10 و G-15، آزمون Maker/Checker/DB هنوز باز |
| R2A | Full Build/JAR PASS در محیط کاربر، Runtime باز | جست‌وجو/شناسنامه فقط‌خواندنی؛ JWT و Oracle واقعی آزمون نشده |
| R2B | **بسته Source قابل ارتقا تحویل شده، Build/JAR محلی در دسترس نیست** | فرم معرفی، استعلام CIF، Validation، Draft Stage؛ DML پیش‌فرض بسته؛ G-03/G-12/G-14/G-17 باز |
| R3-R7 | شروع نشده | مطابق نقشه راه ثابت و Gateهای خود |

**تصمیم غیرقابل تغییر بدون ثبت رسمی:** هیچ شماره انتظامی و شناسنامه قطعی در R2B تولید نمی‌شود؛ پیش‌نویس جدید به نام Collateral ثبت‌شده معرفی نمی‌شود؛ schema جدید نیازمند تأیید DBA/معمار داده است.
