# وضعیت نسخه‌دار نقشه راه CLT-ROADMAP-R1.0 پس از R6C

| فاز ثابت | وضعیت توسعه و شواهد | بدهی باز |
|---|---|---|
| R0 تحلیل و خط مبنا | تکمیل‌شده | حفظ تطبیق اسناد EA/DDL |
| R1 اطلاعات پایه و حاکمیت | سورس توسعه‌یافته | تصمیم‌های سیاستی، Audit، پذیرش واقعی |
| R2 شناسنامه و معرفی | سورس توسعه‌یافته | ثبت قطعی و اصلاحیه، شناسه دارایی/شماره انتظامی |

### اولویت بعدی

آزمون R6C در محیط Windows و مرورگر، سپس بستن مغایرت‌های واقعی UI ثبت‌شده توسط تحلیلگر. هیچ فاز و نام مصوب R0–R7 بازتعریف نشده است. این Patch مستقلاً به عملیاتی‌شدن عملیات مالی ادعا نمی‌کند.
