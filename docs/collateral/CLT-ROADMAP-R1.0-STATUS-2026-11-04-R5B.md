## تغییر نسبت به R5A

- جدید: APIهای Service-only ثبت، Receipt و لغو درخواست مرحله‌ای؛ دفتر خواندنی Analyst، دو جدول کاندید و Audit.
- حفظ‌شده: فقط خواندن تاریخچه تخصیص CLT و Preflight بدون عملیات مالی R5A.
- Default OFF: `CLT_UNALLOCATION_INTAKE_WRITES_ENABLED:false`. SQL فقط پیش‌بررسی؛ هیچ اجرای Oracle.
- عدم تغییر: IAM، CIF، DPS2، ابزارهای مشترک، Route سراسری، نسخه محصول، نقشه راه و نام فازها.

- این ZIP یک ارتقای SHA-256 pinned با Manifest دقیق و Backup/Rollback است.
