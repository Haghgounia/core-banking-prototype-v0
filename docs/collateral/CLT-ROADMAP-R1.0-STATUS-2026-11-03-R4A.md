# CLT — وضعیت نسخه‌دار در پایان تحویل R4A

**Roadmap locked:** `CLT-ROADMAP-R1.0`، فازها R0 الی R7 بدون تغییر نام، محدوده یا ترتیب.

| فاز | وضعیت اثبات‌شده |
|---|---|
| R0 | بررسی اولیه و نقشه راه مصوب در سطح برنامه |
| R1 | کد R1A/R1B در JAR ساخته شده؛ فعال‌سازی Oracle Writer و UAT ستادی هنوز باز |
| R2 | R2A تا R2E ساخته شده؛ ثبت قطعی همچنان غیرفعال (G-01/03/12/14/16/17) |
| R3 | R3A تا R3C Build شده؛ عملیات نهایی ضامن/بیمه/ارزیابی تا تصمیم چرخه عمر باز |
| R4A | شواهد ظرفیت، کسری خام و What-if بدون ثبت؛ Build کامل و Runtime نیازمند تأیید محیط اجرا |
| R4B+ | قرارداد عملیاتی تخصیص/آزادسازی هنوز فعال نشده است |
| R5-R7 | طبق نقشه راه اصلی؛ بدون بازتعریف |

**تغییرات در R4A:** فقط فایل‌های اختصاصی `collateral`، بدون تغییر IAM/CIF/DPS2 یا Root Runtime، بدون اجرای Oracle.

**کنترل‌های پذیرش R4A:** آزمون Policy، هش Manifest، Idempotent Installer، عدم تداخل، Build و JAR، `NG8102=0`، آزمون Runtime خواندنی با JWT و حساب CLT read-only. موفقیت Build به تنهایی اثبات اجرای واقعی API یا تأیید دسترسی بانکی نیست.
