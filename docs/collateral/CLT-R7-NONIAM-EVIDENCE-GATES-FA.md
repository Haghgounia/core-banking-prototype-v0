# R7 — دفتر شواهد آمادگی غیر IAM (وابسته به تکمیل IAM نیست)

این دفتر **مسیر آماده‌سازی R7** است، نه گزارش خاتمه R7. ساختار فازهای R0–R7 تغییر نکرده است.

| حوزه | شاهد قابل تهیه مستقل از IAM | مانع/وضعیت فعلی |
|---|---|---|
| UI و منو | R6B: هفت Route و شش لینک، `ng build` در حضور کامپوننت‌ها | Build واقعی و مرورگر هنوز باید تأیید شود |
| Dictionary Oracle | `database/oracle/clt/r6b/00_CLT_R6B_DICTIONARY_READONLY.sql` | هنوز روی Oracle اجرا نشده؛ فقط SELECT |
| گزارش‌ها | سه GET واقعی، Branch JWT و Read-only Reader | در نبود JWT و Reader فعال، 401/403/503 و بدون داده جعلی |
| مدل ثبت وثیقه | خط‌مبنا و G-01/G-14/G-17 | ثبت قطعی مسدود |
| ضامن، بیمه، ارزیابی | کنترل‌های R3 و G-04..G-07، G-18 | نبود سیاست مصوب و Oracle Runtime |
| تخصیص | R4A–R4D، G-02/G-09/G-13 | تخصیص اتمیک واقعی، قفل سراسری و مصرف‌کننده معتبر باز |
| رفع تخصیص | R5A–R5B و G-19/G-20 | Ledger و FULL/PARTIAL، Reversal و Approval باز |
| آزادسازی | R5C و G-21/G-22 | Hold حقوقی و DPS2، استعلام، وضعیت نهایی باز |
| UAT عملکردی | ۱۰ سناریوی مرجع، خروجی/ورودی JSON | تا بررسی تحلیلگر `NOT_RUN` یا `BLOCKED`؛ نتیجه ساختگی ندارد |
| IAM/IdP | صرفاً گیت‌های فعلی حفظ می‌شوند | اجرای کامل IAM، JWK/IdP و مجوز واقعی هنوز باز؛ این بسته دست نمی‌زند |

**قاعده کنترل تغییر:** هر تبدیل وضعیت از آمادگی فنی به Write بانکی باید دارای مصوبه کسب‌وکار، طرح Migration تأییدشده DBA، مجوز سرویس مصرف‌کننده، آزمون هم‌زمانی/Recovery و UAT مستند باشد. نصب R6B هیچ‌یک را به‌صورت ضمنی فعال نمی‌کند.
