# چک‌لیست کوتاه پذیرش R6C در مرورگر

**همه موارد در ابتدا NOT_RUN هستند. این سند صورت‌جلسه پذیرش نیست.**

| آزمون | اقدام تحلیلگر | انتظار | نتیجه اولیه |
|---|---|---|---|
| R6C-U01 | فهرست را باز و شماره فارسی ۱۹رقمی مجاز را فیلتر کند | بدون تغییر دقت، نتیجه شعبه مجاز و صفحه‌بندی | NOT_RUN |
| R6C-U02 | شماره نامعتبر، صفر پیشرو و ۲۰رقمی را وارد کند | عدم ارسال به API | NOT_RUN |
| R6C-U03 | استعلام مستقیم با ارقام فارسی/عربی | ارسال همان رشته ASCII معتبر و نمایش شناسنامه مجاز | NOT_RUN |
| R6C-U04 | بین فهرست، معرفی، گزارش و UAT رفت‌وبرگشت کند | URL و Back/Forward با نمایش فرم منطبق باشند | NOT_RUN |
| R6C-U05 | از پوشش ۱۵ نما «ارزیابی» را باز کند | به استعلام شماره هدایت و پس از Lookup بخش ارزیابی انتخاب شود | NOT_RUN |
| R6C-U06 | در UAT نتیجه‌ای ثبت و به گزارش‌ها رفته بازگردد | وضعیت در حافظه نشست SPA حفظ شود | NOT_RUN |
| R6C-U07 | نتیجه بدون توضیح شاهد ثبت کند | هشدار نقصان شواهد، بدون PASS خودکار | NOT_RUN |
| R6C-U08 | JSON صادر و مجدداً وارد کند | تعداد ۱۰ سناریو، برچسب‌ها و وضعیت‌ها ثابت بمانند | NOT_RUN |
| R6C-U09 | گزارش را در شرایط پاسخ 401/403 فراخوانی کند | خطای مجوز بدون داده نمایشی | NOT_RUN |
| R6C-U10 | ناوبری و جدول‌های عرض ۱۳۶۶ و موبایل را بررسی کند | Scroll/RTL/Focus بدون هم‌پوشانی | NOT_RUN |

ثبت نتایج باید با شناسه سناریو، شواهد غیرمحرمانه، نسخه مرورگر و تاریخ انجام شود. برای سناریوهای فاقد داده واقعی، `BLOCKED` به‌جای `PASS` ثبت شود.
