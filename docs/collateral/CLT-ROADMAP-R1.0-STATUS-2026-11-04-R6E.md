# وضعیت خط مبنای CLT-ROADMAP-R1.0 — تحویل R6E

| فاز | وضعیت تا ۱۴۰۵/۰۸/۱۳ |
|---|---|
| R0 — تحلیل خط مبنا | تکمیل خط مبنا |
| R1 — اطلاعات پایه و حاکمیت قواعد | توسعه موجود، پذیرش نهایی باز |
| R2 — شناسنامه، معرفی، جست‌وجو | توسعه موجود، ثبت قطعی باز |
| R3 — ضامن، بیمه، ارزیابی | توسعه موجود، تأیید چرخه‌های بانکی باز |
| R4 — ظرفیت و تخصیص | توسعه R4A–R4D، تخصیص واقعی غیرفعال |
| R5 — رفع تخصیص، آزادسازی، سوابق | توسعه R5A–R5C، آزادسازی مالی غیرفعال |
| **R6 — تکمیل UI و UAT** | R6A–R6D با Build گزارش‌شده؛ **R6E تحویل سورس و QA مستقل؛ Runtime/UAT منتظر شواهد واقعی** |
| R7 — یکپارچه‌سازی و آماده‌سازی | باز؛ فعالیت‌های مستقل از سایر دامین‌ها قابل پیشبرد |

**گام بعدی:** جمع‌آوری خروجی واقعی کنترل‌های R6D/R6E و اصلاح مغایرت‌های مشخص‌شده در همین ماژول؛ سپس پیگیری بستن شکاف‌های R1–R5. هیچ تغییری در نام فازهای R0–R7 اعمال نشده است.
