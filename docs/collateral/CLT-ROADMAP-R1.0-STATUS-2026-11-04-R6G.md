## وضعیت نسخه
- منبع: `core-banking-prototype-v0-2026-11-04-1518.zip`؛ نسخه `0.11.0`.
- فایل‌های تغییر یافته: فقط کد Backend CLT، قرارداد نمایش نتیجه R6D و مستندات CLT.
- Read-only: بله در مسیرهای HTTP و SQL این Patch؛ در حالت DEV از حساب برنامه استفاده می‌شود؛ Oracle user ذاتاً SELECT-only نیست.
- Build واقعی Maven/Angular و Oracle در ماشین توسعه‌دهنده باید در Installer و Runtime کنترل شود.
- Next: تأیید 4/4 R6D، R6E بر مبنای شناسه موجود و بازبینی فهرست واقعی شکاف‌ها برای بسته تجمیعی بعدی. گزارش‌ها مجوز عملیات مالی تلقی نمی‌شوند.

## بدهی QA موجود در خط مبنا
- آزمون آفلاین R6A با `CLT_R6A_TEST_FAIL:GENERATED_RUNTIME_SOURCE_HASH` روبه‌رو است. هر سه فایل دخیل (`collateral-r6a-catalog.ts`, `uat-catalog-runtime.cjs`, `CLT-R6A-UAT-OFFLINE.html`) با ZIP مبنا یکسان‌اند؛ این مغایرت پیش از R6G وجود داشت و به قابلیت خواندنی جدید مرتبط نیست.
- آزمون‌های قراردادی R6C، R6D، R6E و ایمنی ایستای R6G موفق بوده‌اند؛ JUnit/Maven/Angular/Oracle هنوز در محیط کاربر انجام نشده‌اند.
