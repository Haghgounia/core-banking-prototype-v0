# CLT-R3C — کاتالوگ شرکت‌های بیمه و UAT تحلیلگر

**مبنای سورس:** Core Banking Prototype 0.11.0 + R6M، همراه با API مرجع CLT/R1A و قواعد R3B.
**دامنه:** صرفاً UI و مستندات؛ بدون تغییر Backend، امنیت، DDL، DML، IAM یا ساختار داده.
**تاریخ:** ۱۴۰۵/۰۸/۱۶ (۲۰۲۶-۱۱-۰۷)

## مسیر ورود

`http://127.0.0.1:8091/#/collateral/reference-data/INSURANCE_COMPANY`

از منوی «مدیریت وثایق → شرکت‌های بیمه (مرجع)» یا از پیوند در پنل بیمه‌نامه وثیقه قابل دسترسی است.

## حقایق فنی قطعی در سورس

- API کاتالوگ: `GET /api/v1/collateral/reference/INSURANCE_COMPANY?page=0&size=20`؛ همه وضعیت‌ها، صفحه‌بندی ۲۰تایی، جست‌وجوی کد/نام. نگاشت به `CLT.INSURANCE_COMPANY` در Allowlist رسمی مرجع موجود است.
- API انتخابگر بیمه‌نامه در `CollateralInsuranceRepository.options` از `CLT.INSURANCE_COMPANY WHERE STATUS = 'ACTIVE'` می‌خواند؛ غیرفعال‌ها قابل انتخاب نیستند.
- `INSURANCE_COMPANY_CODE` برای ۴۲ رکوردِ نامزد، **کد موقت** `TMP-INS-1403-*` است؛ هیچ یک به عنوان کد رسمی بیمه مرکزی احراز نشده‌اند.
- تعداد مشاهده‌شده در مرورگر به **COMMIT در همان نشست Oracle** وابسته است. پاسخ ۴۲ ردیفیِ قبل از COMMIT نشانه ماندگاری برای سایر نشست‌ها نیست.
- ستون‌های جدول در قرارداد مرجع شامل شناسه، کد، نام، STATUS و شواهد Audit (CREATED/UPDATED، RECORD_VERSION) هستند.
- هیچ API جدید یا مسیر نوشتن در R3C ساخته نشده و UI تغییرات حاکمیتی برای `INSURANCE_COMPANY` را تا طراحی Policy Approval مستقل مخفی نگه می‌دارد.

## سناریوهای UAT تحلیلی

| کد | سناریو | انتظار | گیت |
|---|---|---|---|
| R3C-UAT-01 | ورود از منوی وثایق و پیوند پنل بیمه | نمایش کاتالوگ واقعی Oracle، نه Mock | فقط‌خواندنی |
| R3C-UAT-02 | فهرست کامل پس از COMMIT با داده نامزد | در صورت موجودبودن ۴۲ رکورد: سه صفحه ۲۰/۲۰/۲ | داده COMMIT شده |
| R3C-UAT-03 | جست‌وجوی نام «بیمه ایران» یا کد `TMP-INS-1403-001` | فیلتر مطابق داده واقعی و امکان پاک‌سازی | ثبت کارکرد |
| R3C-UAT-04 | مشاهده جزئیات | Modal مرکزی R6M؛ Escape و حفظ موقعیت جدول | R6M |
| R3C-UAT-05 | بررسی وضعیت رکورد | ۴۲ نامزد باید INACTIVE باشند مگر بانک عمداً وضعیت را تغییر داده باشد | داده واقعی |
| R3C-UAT-06 | پنل انتخاب بیمه‌نامه | نامزدهای INACTIVE انتخاب‌پذیر نیستند؛ پیام نبود شرکت فعال روشن است | بدون عملیات نهایی |
| R3C-UAT-07 | مراجعه در صورت خطای Oracle/HTTP | پیام خطا؛ نتیجه صفر نباید به عنوان نبود داده قطعی معرفی شود | کنترل خطا |

## شکاف‌های باز

- **INS-DATA-01:** تطبیق با مرجع رسمی بیمه مرکزی، شناسه/کد مصوب و اعتبار پروانه.
- **INS-DATA-02:** نوع مؤسسه، قلمرو جغرافیایی و رشته‌های مجاز بیمه در جدول نه ستون مستقل دارند و نه قواعد تصمیم بانک.
- **INS-BIZ-01:** معیار «قابل انتخاب برای بیمه وثیقه» نباید صرفاً STATUS=ACTIVE باشد؛ تا تصویب سیاست پذیرش بانک، گیت نهایی باز است.
- **G-04 و G-06:** انواع پوشش الزامی و چرخه تأیید/لغو بیمه‌نامه هنوز مصوب و نهایی نیستند.
- **G-09:** API شرکت بیمه طرف قرارداد بانک در دسترس نیست.

**قضاوت آمادگی:** R3C فقط کاتالوگ و کنترل منفی انتخاب را برای UAT آماده می‌کند؛ نه تأیید بیمه‌نامه و نه تخصیص وثیقه را.
