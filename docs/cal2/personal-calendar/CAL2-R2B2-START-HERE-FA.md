# CAL2 R2-B2 Pilot - راه اندازی اصلاح شده FIX2

**اشکال FIX1:** فایل های افزوده شده به ریشه پروژه، در `verify-release-layout.mjs` مردود بودند. در FIX2 هیچ فایل اضافی در ریشه نیست. فایل اجرایی به `tools/RUN-CAL2-R2B2-PILOT.cmd` منتقل شده است.

## روش نصب روی همان مسیر پروژه

1. از پروژه بکاپ بگیرید. Patch جدید `CAL2-R2B2-PATCH-LAYOUT-FIX2-2026-10-24.zip` را روی ریشه پروژه استخراج کنید و ساختار پوشه ها را حفظ کنید.
2. **دیگر فایل `RUN-CAL2-R2B2-PILOT.cmd` قدیمی در ریشه را اجرا نکنید.**
3. از مسیر `D:\Projects\core-banking-prototype-v0` فرمان زیر را اجرا کنید:

```cmd
call tools\RUN-CAL2-R2B2-PILOT.cmd
```

4. اسکریپت جدید، چهار فایل قدیمی FIX1 را در صورت وجود به `docs\cal2\personal-calendar\r2b2-package` منتقل می کند (بدون حذف یا بازنویسی)، سپس کنترل چیدمان ریشه را اجرا می کند.
5. پس از موفقیت کنترل، اعتبارسنجی ایستا، Build و اجرای برنامه انجام می شود. نشانی پیش فرض: `http://localhost:8091`.

**آزمون فقط خواندنی Oracle:** قبل از UAT فایل `database/oracle/cal2/verification/CAL2-R2B2-CONTRACT-VERIFY-READONLY.sql` را با SQL Developer و F5 اجرا کنید. اجرای خودکار CMD هیچ SQL روی Oracle اجرا نمی کند.

**ملاحظات:** حالت تک کاربره DEMO و Scheduler صرفا در پردازش اجرا شده با این CMD فعال اند، نه برای محیط عملیاتی. روی Windows و Oracle واقعی هنوز اجرای نهایی تایید نشده است. اگر Build خطای بعدی داد، خطای جدید را ارسال کنید. در صورت وجود همزمان یک فایل قدیمی در ریشه و پوشه مقصد، عملیات برای جلوگیری از بازنویسی متوقف می شود.

## بررسی دستی رفع خطا

```cmd
node tools\verify-release-layout.mjs
node tools\verify-cal2-personal-r2b2.mjs
```

**مهم:** اگر فایل های FIX1 را قبلا به یک زیرپوشه منتقل کرده اید، اسکریپت هیچ جابه جایی اضافه ای انجام نمی دهد.
