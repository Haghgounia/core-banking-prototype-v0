# راه‌اندازی CAL2 R2-B2 Pilot در Windows

این نسخه **آزمایشی و تک‌کاربره** است؛ برای محیط عملیاتی بانکی مناسب نیست.

## اگر نسخه کامل پروژه را دریافت کرده‌اید

1. فایل ZIP کامل را در یک پوشه جدید استخراج کنید.
2. در ریشه پوشه استخراج‌شده، فایل `RUN-CAL2-R2B2-PILOT.cmd` را اجرا کنید (یا در CMD نام آن را وارد کنید).
3. این فایل ابتدا آزمون ایستای R2-B2 را اجرا می‌کند، سپس با `build-production.cmd` پروژه را می‌سازد و با `bin\start.cmd` سرویس را اجرا می‌کند.
4. پس از راه‌اندازی موفق، نشانی `http://localhost:8091` را در مرورگر باز کنید.

## اگر فقط Patch را دریافت کرده‌اید

1. از پوشه فعلی پروژه نسخه پشتیبان تهیه کنید.
2. محتویات ZIP پچ را **مستقیماً روی ریشه پوشه پروژه** استخراج کنید؛ ساختار پوشه‌ها حفظ و فایل‌های هم‌نام جایگزین شوند.
3. بررسی کنید `RUN-CAL2-R2B2-PILOT.cmd` در کنار `build-production.cmd` قرار گرفته باشد، نه در یک زیرپوشه اضافه.
4. همان فایل CMD را اجرا کنید و سپس `http://localhost:8091` را باز کنید.

## پیش‌نیازها و ملاحظات

- Java 21، Node.js و npm، Maven Wrapper با دسترسی به وابستگی‌های موردنیاز، و فایل پیکربندی معتبر `config\application.yml` لازم‌اند.
- ZIP نسخه کامل **سورس** است و فایل JAR آماده اجرا ندارد؛ بنابراین اجرای موفق Build ضروری است.
- قبل از UAT، اسکریپت فقط‌خواندنی `database/oracle/cal2/verification/CAL2-R2B2-CONTRACT-VERIFY-READONLY.sql` را در SQL Developer با `F5` اجرا کنید. پیام مورد انتظار: `CAL2_R2B2_READONLY_CONTRACT_PASS`.
- فایل CMD هیچ دستور DDL یا DML را روی Oracle اجرا نمی‌کند و پردازش در حال اجرا را خودکار متوقف نمی‌کند.
- فایل CMD صرفاً برای Pilot محلی، متغیرهای `CAL2_PERSONAL_R2B2_DEMO_ENABLED=true` و `CAL2_PERSONAL_R2B2_SCHEDULER_ENABLED=true` را در همان پردازش تنظیم می‌کند. این حالت به‌هیچ‌وجه برای محیط چندکاربره یا عملیاتی مجاز نیست.
- اگر پورت ۸۰۹۱ اشغال باشد، اجرای جدید متوقف می‌شود تا نسخه قبلی به‌اشتباه جایگزین نشود.
- اگر Build با خطای Maven یا Angular مواجه شود، برنامه اجرا نخواهد شد؛ خطای واقعی در پنجره CMD نمایش داده می‌شود.

**وضعیت آزمون:** صحت بسته ZIP، کنترل‌های ایستای سورس و ساختار فایل CMD قابل بررسی است؛ اجرای واقعی CMD روی Windows و آزمون یکپارچه Oracle هنوز در این محیط انجام نشده است.
