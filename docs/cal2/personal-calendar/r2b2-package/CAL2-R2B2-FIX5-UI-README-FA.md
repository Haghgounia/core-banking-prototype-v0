# CAL2 R2-B2 — FIX5 / اصلاح رابط کاربری یادداشت، کار و قرار

## دامنه دقیق اصلاح

در صفحه تقویم ماهانه، فرم ثبت/ویرایش مدخل شخصی از ستون باریک ۳۳۰ پیکسلیِ جزئیات روز خارج شده و در پنجره مناسبِ تمام‌صفحه با عرض حداکثر ۶۴۰ پیکسل و اسکرول مستقل باز می‌شود. این کار فقط نمایشی است و هیچ مدل داده، API یا سرویس بانکی تغییر نکرده است.

- فیلدهای تاریخ، عنوان، توضیحات، ساعت شروع، تکرار، ساعت پیام، روزهای پیش از موعد و دوره تکرار پیام باقی مانده‌اند.
- راهنمای بلند ساعت‌گزین برای این فرم کوتاه شده تا متن زیر فیلد روی کنترل بعدی نیفتد.
- راهنمای تعداد روزهای قبل از موعد به فضای مستقل زیر فیلد منتقل شده است.
- فوکوس صفحه داخل فرم نگه داشته می‌شود؛ فیلد عنوان فوکوس اولیه است و بستن با Esc، دکمه ضربدر و انصراف ممکن است.
- خطای ذخیره در خود فرم نشان داده می‌شود، نه در بخش پنهانِ جزئیات روز.
- پنجره در موبایل هم واکنش‌گرا است.
- یک کنترل ایستای اختصاصی به build-production.cmd و build-production.sh اضافه شده است.

## نصب روی سورس فعلی پس از FIX4

در حالت بسته بودن برنامه، از مسیر پروژه فعلی نسخه پشتیبان تهیه کنید. محتویات ZIP را روی **ریشه** `D:\Projects\core-banking-prototype-v0` استخراج و فایل‌های مشترک را جایگزین کنید. فایل‌های جانبی این Patch همگی زیر `docs/` و `tools/` هستند؛ چیزی به ریشه اضافه نمی‌شود.

### آزمون قبل از Build (CMD)

```cmd
cd /d D:\Projects\core-banking-prototype-v0
node tools\verify-cal2-personal-form-layout.mjs
node tools\verify-time-picker.mjs
node tools\verify-cal2-personal-r2b2.mjs
node tools\verify-release-layout.mjs
call tools\RUN-CAL2-R2B2-PILOT.cmd
```

### آزمون دستی

1. از `http://localhost:8091/calendar2/month-view` یکی از روزها را انتخاب کنید.
2. هر سه نوع «یادداشت»، «کار» و «قرار ملاقات» را باز کنید. فرم باید در پنجره مرکزی عریض باز شود نه ستون باریک کنار تقویم.
3. «ساعت شروع» و «یادآوری» را فعال کنید؛ برچسب‌ها، مقدار ساعت، راهنما و فیلد بعدی نباید هم‌پوشانی داشته باشند.
4. روی انتخاب ساعت کلیک کنید؛ منوی ساعت گرافیکی باید بالای پنجره فرم دیده شود.
5. حالت موبایل یا عرض کم مرورگر را آزمایش کنید؛ فرم باید اسکرول مستقل داشته باشد و دکمه ذخیره/انصراف قابل دسترس باشد.
6. Esc، انصراف و ذخیره را امتحان کنید. صحت ذخیره واقعی در Oracle باید در محیط UAT شما جداگانه بررسی شود.
