## قواعد تبدیل
### درصد
در Excel عدد ستون «درصد» در واحد درصد است. در موتور:
`RATE_VALUE = source_percent / 100`

نمونه‌ها:
- `0.5` => `0.005`
- `0.02` => `0.0002`
- `0.0001` => `0.000001`

### پلکانی ارزیابی
پنج تعرفه فیزیکی سه‌ردیفی به یک تعریف + سه Tier تبدیل می‌شوند. پله دوم «دو در هزار نسبت به مازاد» و شرط «کمتر بودن از تعرفه کارشناس رسمی» با Rule Component و External Value مدل می‌شود. پله سوم بالای 400 میلیارد ریال External است.

### داده مبهم
وقتی ستون‌های ساختاری Excel فرمول کامل ارائه نمی‌کنند، فقط متن منبع نگهداری و Strategy=`EXTERNAL_VALUE` می‌شود؛ هیچ عدد یا فرمولی از متن حدس زده نمی‌شود.

ROLLBACK`، خطای DML یا Verification پیش از Commit باعث Rollback همان اجرا می‌شود.
