# NAV-R22.1 — اصلاح نمایش منوی اصلی (مستقل از Product Builder)

## هدف

در نسخه R22 در عرض محدود نوار کناری، عنوان «موتور جدید کارمزد — FEE2» در تصویر کاربر به صورت بریده دیده می‌شد. این بسته دو عنوان را به «مدیریت کارمزد (FEE)» و «موتور کارمزد (FEE2)» کوتاه می‌کند، عنوان کامل/قبلی را در Tooltip حفظ می‌کند و به لینک‌های طولانی زیرمنو اجازه شکست سطر می‌دهد. نمایش آیکون‌ها در حالت منوی جمع‌شده تغییری نمی‌کند.

## دامنه و ایمنی

- **هیچ فایل `app-shell` قدیمی در ZIP وجود ندارد.** نصب‌کننده فایل موجود در پروژه را می‌خواند و تنها متن و Tooltip دو لینک FEE/FEE2 را به شکل هدفمند تغییر می‌دهد.
- اصلاح CSS فقط به کامپوننت مستقل `sidebar-r22` اعمال می‌شود؛ فایل قبلی SCSS هم در ZIP جایگزین نمی‌شود.
- تمام مسیرها و ترتیب منو، لینک‌های Product Builder، FEE و FEE2 دست‌نخورده‌اند. فرم‌ها، API، Oracle، جاوا، Breadcrumb، Routing و فایل‌های محصول‌ساز تغییر نمی‌کنند.
- نصب‌کننده اگر R22 نصب نباشد، منو دچار تغییر پیش‌بینی‌نشده باشد یا وضعیت نصب ناقص باشد، بدون بازنویسی سورس متوقف می‌شود.
- اسکریپت وضعیت قبلی دو عنوان/Tooltip را در `docs/patch-backups/nav-r221/sidebar-visual-state.json` ذخیره می‌کند؛ بازگشت به صورت هدفمند روی همان موارد انجام می‌شود.
- **فقط روی نسخه‌ای نصب شود که R22 روی آن فعال است.** برای تغییرات هم‌زمان تیم محصول، ابتدا سورس جدید آنها را وارد کنید و سپس این Patch را اجرا کنید.

## نصب در Windows CMD

ابتدا نسخه پشتیبان از پروژه تهیه کنید. ZIP را در ریشه پروژه استخراج کنید (فقط فایل‌های `tools/` و `docs/`). سپس:

```bat
cd /d D:\Projects\core-banking-prototype-v0
node tools\install-nav-r221.mjs
node tools\verify-nav-r221.mjs
node tools\verify-r22-sidebar.mjs
node tools\verify-fee2-studio.mjs
node tools\verify-pdl-r29-finalization.mjs
build-production.cmd
```

سپس در مرورگر، لینک‌های FEE و FEE2 را در حالت باز، جمع‌شده و عرض پنجره کم بررسی کنید. عنوان هر دو باید کامل باشد یا نهایتاً به خط دوم منتقل شود، نه سه‌نقطه. لینک استودیوی FEE2 صرفاً در صفحه موتور جدید موجود است.

## بازگشت

```bat
cd /d D:\Projects\core-banking-prototype-v0
node tools\uninstall-nav-r221.mjs
node tools\verify-r22-sidebar.mjs
build-production.cmd
```

ابزار بازگشت فقط متن/Tooltip قبلی FEE/FEE2 و بلوک CSS افزوده‌شده را بازیابی می‌کند و لینک‌های جدید دیگر را حفظ می‌کند. اگر تیم دیگری خود دو لینک را تغییر داده باشد، بازگشت برای جلوگیری از بازنویسی تغییر آنها متوقف می‌شود.

## حدود آزمون

آزمون‌های اسکریپتی و مقایسه فایل‌ها جایگزین Build واقعی Angular/Java و کنترل مرورگر نیستند. هیچ دستور SQL برای این Patch لازم نیست. این بسته نسخه کامل پروژه نیست و نباید با استخراج ZIP نسخه قدیمی محصول‌ساز جایگزین شود.
