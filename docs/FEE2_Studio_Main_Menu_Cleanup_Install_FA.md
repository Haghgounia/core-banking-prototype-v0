# FEE2 Studio — حذف لینک تکراری از منوی اصلی

**مبنای کنترل:** کد پروژه 2026-10-11-1913 به‌همراه Patch نصب‌شده FEE UX R2.1.

## تغییر

- در `frontend/src/app/layout/app-shell.component.html`، فقط لینک مستقل «استودیوی کارمزد FEE2» از بخش «محصولات و قیمت‌گذاری» در نوار کناری اصلی حذف شد.
- لینک «مدیریت کارمزد» (`/fee`) و «موتور کارمزد جدید» (`/fee2`) باقی می‌مانند.
- لینک «ورود به استودیو» در صفحه «موتور کارمزد جدید» (`/fee2`) و مسیر `/fee2/studio` باقی می‌مانند.
- هیچ فایل Backend، FEE، FEE2، Oracle یا Router تغییر نکرده است. اسکریپت تست قدیمی `tools/verify-fee2-studio.mjs` برای انتظار جدید ناوبری اصلاح شده است.

## نصب

1. از پروژه پشتیبان بگیرید و Runtime را متوقف کنید.
2. این ZIP را در `D:\Projects\core-banking-prototype-v0` استخراج کرده و برای فایل هم‌نام گزینه Replace را بزنید.
3. در CMD، داخل پروژه، اجرا کنید:

```bat
node tools\verify-fee2-studio-menu-cleanup.mjs
node tools\verify-fee-ux-r21.mjs
node tools\verify-fee2-studio.mjs
build-production.cmd
```

4. پس از Build موفق، `bin\start.cmd` را اجرا کنید.
5. در نوار کناری، «مدیریت کارمزد» و «موتور کارمزد جدید» باید دیده شوند اما «استودیوی کارمزد FEE2» نباید به‌صورت مستقل دیده شود. وارد «موتور کارمزد جدید» شوید و دکمه «ورود به استودیو» را آزمون کنید.

**نکته:** این Patch فاقد SQL است و صرفاً یک تغییر Navigation است. اگر در نسخه محلی شما `app-shell.component.html` از زمان ZIP ساعت ۱۹:۱۳ تغییر کرده، قبل از جایگزینی آن را با نسخه Patch تطبیق دهید.
