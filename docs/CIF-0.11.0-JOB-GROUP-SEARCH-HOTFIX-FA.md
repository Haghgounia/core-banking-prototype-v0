# CIF 0.11.0 — Job Group Search Hotfix

## Scope
صفحه `/#/cif/parties/:partyId/onboarding/financial-employment`

## تغییر
- فیلد «گروه شغلی» از dropdown ساده به `SearchableCombo` استاندارد برنامه تبدیل شد.
- جستجو از endpoint موجود `reference/job-groups/lookup` استفاده می‌کند و DDL/API جدیدی اضافه نشده است.
- تغییر گروه شغلی همچنان شغل انتخاب‌شده را پاک کرده و lookup «شغل» را برای گروه جدید reload می‌کند.
- هنگام ویرایش رکورد موجود، reset فرم با `emitEvent:false` انجام می‌شود تا مقدار شغل قبلی به‌اشتباه پاک نشود.

## Acceptance
1. تایپ بخشی از عنوان گروه شغلی باید لیست را فیلتر کند.
2. انتخاب گروه باید `occupationGroupCode` را مقداردهی کند.
3. بعد از انتخاب گروه، فیلد «شغل» فعال و نتایج آن محدود به همان گروه شود.
4. تغییر/پاک‌کردن گروه باید شغل قبلی را پاک کند.
5. ویرایش سابقه موجود نباید occupation قبلی را در زمان patch فرم از دست بدهد.
