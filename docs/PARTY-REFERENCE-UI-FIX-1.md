# Party Reference UI Fix 1

نسخه برنامه همچنان `0.3.2-prototype` است. این اصلاح فقط چیدمان فرم‌های Party Reference را با فرم‌های استاندارد اطلاعات پایه پروژه همسان می‌کند.

- Metadata فنی از UI عملیاتی حذف شد.
- Grid به ستون‌های اصلی کاربری محدود شد.
- Editor از همان الگوی فرم‌های استان/شهر/روستا استفاده می‌کند.
- `RECORD_VERSION` پشت صحنه برای Optimistic Lock حفظ شده است.
- DDL و Seed Data تغییری نکرده‌اند.
