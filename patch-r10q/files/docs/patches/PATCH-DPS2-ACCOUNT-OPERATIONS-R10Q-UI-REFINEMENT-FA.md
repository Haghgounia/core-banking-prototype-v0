# R10Q — پالایش حرفه‌ای UI عملیات حساب

Baseline هدف: `core-banking-prototype-v0-2026-10-04-1409` به‌همراه تغییرات تجمعی R10P-HF1.

## اصلاحات

- مرحله ۰۷ «مدیریت سقف‌ها و محدودیت‌های حساب» به دو پنل مستقل و مشخص تفکیک شد:
  - انواع سقف حساب
  - محدودیت بر اساس نوع تراکنش
- بین دو پنل فاصله، Border، Header، متن توضیحی و Responsive behavior مستقل اضافه شد.
- کنترل «مرجع الزام / تأیید» همچنان Selector کنترل‌شده باقی ماند و به Edit Box برنگشت.
- فرآیند `ops-closure` از Card مستقل و همیشه‌قابل‌مشاهده خارج و داخل Workspace واقعی مرحله ۰۸ قرار گرفت.
- عنوان تکراری «بستن و بازگشایی کنترل‌شده حساب» از UI قابل‌مشاهده حذف شد؛ Contract قدیمی فقط به‌صورت hidden marker برای Regressionها حفظ شد.
- مرحله ۰۸ اکنون دو زیرپنل روشن دارد:
  - پردازش سررسید
  - ثبت و پیگیری بستن / بازگشایی
- فرم ثبت درخواست و بخش «درخواست‌های جاری و سابقه اقدام» از نظر بصری جدا شدند.
- Actionهای تأیید و اجرا با عنوان‌های صریح‌تر نمایش داده می‌شوند.

## دامنه فنی

این Patch تغییر DDL یا Migration ندارد و رفتار Business/Backend بستن حساب، بازگشایی، سقف و محدودیت را تغییر نمی‌دهد؛ تغییرات فقط ساختار نمایش و سازمان‌دهی UI هستند.
