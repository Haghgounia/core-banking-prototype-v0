## شواهد/محدودیت

- آخرین شواهد مستند در ۷ نوامبر برای گروه‌های CLT (`28`)، انواع فعال (`0`) و شناسنامه‌های عملیاتی (`0`) است؛ **این اعداد ادعای شمار زنده ۸ نوامبر نیستند**.
- فرم `INSURANCE_COMPANY` با ۴۲ بیمه‌گر آزمایشی/غیرفعال در سابقه قبلی ثبت شده؛ **فعال‌سازی/تأیید صلاحیت این‌ها از UI نتیجه نمی‌شود**.
- رابط ۱۷ جدول Reference در `CLT UI R3` به Material Table/Sort/Paginator ارتقا یافته است؛ `SYS-UI-V1` فقط لایه ارائه سراسری و کنترل‌های تاریخ/تم/دسترس‌پذیری را اضافه می‌کند.
- ثبت قطعی، تخصیص و آزادسازی تا تصویب قواعد و شواهد واقعی کسب‌وکار گشوده نمی‌شود؛ G-16/G-17 و سایر شکاف‌ها از نقشه راه مرجع حذف نشده‌اند.
- هیچ API/Backend/Schema/Oracle DML، منطق یا پیکربندی IAM، یا DataSource در این تغییر تغییر نکرده است؛ قالب نمایشی IAM فقط Scope استایل مشترک گرفته است. اجرای محلی فقط از Starter مشترک `bin/start.cmd` استفاده می‌کند.
- آزمون‌های طراحی و Accessibility ایستا، معادل UAT مرورگر و آزمون تراکنش نیستند.
