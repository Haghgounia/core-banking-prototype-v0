Core Banking Prototype 0.3.86 - FIX94
Shared Material Time Picker / HH:mm Contract

هدف
- جایگزینی تمام inputهای native از نوع time با Time Picker مشترک و سازگار با Theme.
- استفاده از Angular Material Timepicker با نمایش 24 ساعته و Interval انتخابی 5 دقیقه.
- حفظ قرارداد Backend/Oracle به صورت HH:mm بدون تبدیل به Date/Timestamp.
- افزودن FieldType.TIME واقعی به Metadata لایه CAL2.

دامنه تغییر
- CAL2: الگوی هفتگی ساعات کاری و استثناهای تک روز.
- CAL: تمام Fieldهای metadata از نوع TIME.
- CIF: ساعات مجاز تماس و ترجیح زمان تماس.

Database
- هیچ DDL یا Migration جدیدی لازم نیست.
- ستون های FIX93 همچنان VARCHAR2(5 CHAR) با قرارداد HH24:MI باقی می مانند.
