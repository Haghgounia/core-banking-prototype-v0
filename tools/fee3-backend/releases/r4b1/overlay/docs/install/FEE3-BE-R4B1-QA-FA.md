# گزارش کنترل FEE3-R4B1 — 2026-10-27

## آزمون‌های محلی اجراشده

- Source/Java: تولید کد روی JDK21، تست‌های عددی مستقل `Fee3R4B1Probe.java`، و کامپایل امضای چهار کلاس Java در برابر Stubهای Spring و Jackson/JUnit.
- HTTP: سرور Mock محلی با direct-loopback، عدم تبعیت از Proxy، deny-all برای عملیات نوشتنی، جلوگیری از Redirect به مقصد خارجی و رد ارتباط با میزبان غیرمحلی.
- صحت عددی: ۳۰ میلیون ریال پلکانی → ۲۰ هزار ریال؛ ۱۰ میلیون ریال در مرز بازه دوم → ۸ هزار ریال؛ ۹٬۹۹۹٬۹۹۹ ریال در بازه نخست → ۲۰ هزار ریال؛ نرخ و جزء ثابت در پله‌های دارای سهم مثبت، کف و سقف نهایی، مالیات صریح، گردکردن HALF_UP/HALF_EVEN و سقف خروجی.
- منفی/Fail-closed: خلأ و هم‌پوشانی بازه، مرز غیرصعودی، پله باز قبل از انتها، ۳ رقم اعشار مبلغ، نرخ بیش از ۸ رقم اعشار، نرخ بالاتر از ۱۰۰۰٪، حذف نرخ/مبلغ ثابت پله، `UNIT_RATE`، مبنای ضمنی/تعداد، تخفیف/بخشودگی بدون مجوز، تاریخ گذشته، نوع فرمولی، شناسه ناقص Oracle و Overflow.

## محدودیت‌های اثبات

- Compile در برابر Stub **جایگزین Build کامل Spring Boot نیست**. موفقیت نهایی API و تعامل Oracle باید روی Build واقعی Windows و Runtime واقعی ثبت شود.
- روش‌های FIXED/PERCENT/MIXED در R4-A قبلاً در Oracle پذیرفته شده‌اند و این Patch هیچ تغییر در آن‌ها نمی‌دهد.
- نتایج یک نمونه عددی با نرخ نمایشی به معنی تایید مرجع مقررات سال ۱۴۰۵ یا تامین سند بانکی نیست.
- سناریوهای معافیت اصل کارمزد، نرخ بر اساس مصرف، واحدهای پول خارجی، مالیات غیرصریح و انتخاب خودکار تعرفه عمداً بسته‌اند.
- هیچ Oracle DDL/DML، هیچ تغییر Angular، و هیچ تغییر در کلاس‌های قبلی R3/R4-A در Patch وجود ندارد.
