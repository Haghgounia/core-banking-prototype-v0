# FEE3 R4-C1 — گزارش QA و خطرات باز

## مبنای پذیرش قبلی

`FEE3_R4B2_RUNTIME_PASS=26 FAIL=0` روی Backend متصل به Oracle، با وجود غیرفعال‌بودن نوشتن و Posting. خروجی R4C0 واقعی ۱۱ سود، ۲۷ خسارت، ۴ قرض‌الحسنه، همگی DRAFT/غیرفعال را تأیید کرد.

## آزمون مستقل و محلی

- `run-pure-java.py`: کامپایل مستقیم **کلاس واقعی** هسته جدید و اجرای کنترل‌های مرزی و منفی Java. بدون Spring/Oracle.
- `verify-java.py`: کامپایل ۵ کلاس Java و تست JUnit با Stub امضای Spring/JDBC؛ **نه** Build Maven.
- `verify-r4c1.py`: کنترل مسیر API، سیاست نوشتن/گردکردن/تقویم و وجود فایل‌ها.
- `selftest.py`: کنترل پروتکل HTTP، عدم ارسال POST هنگام فعال بودن نوشتن/Workflow یا فقدان مرجع فرمول، عدم پذیرش فقدان CAL2، ممنوعیت مسیرهای نوشتن. صرفاً Mock.
- Runtime واقعی فقط با دستور `run-runtime-readonly.cmd` در محیط Oracle انجام می‌شود.

## خطرات باز و محدودیت‌های اثبات

1. ۹ نسخه `EXCLUDE_ALL_HOLIDAYS` بدون Vocabulary متناظر؛ تصمیم ماهیت دو سیاست و اصلاح نسخه‌های DRAFT منوط به بررسی کارشناسی.
2. ۱۸ ارجاع `QA_CALENDAR_SIMULATION_NOT_APPROVED` هنوز مرجع تقویم مصوب نیستند.
3. ۱/۰، ۱/۰ و ۰/۰ موارد آزمون رسمی Oracle برای سود، خسارت و قرض‌الحسنه؛ پوشش تست کم است.
4. همه ۱۱ نسخه سود `UNREVIEWED` و غیرقابل انتشار؛ نمونه‌های مثبت R4-C1 فقط Unsaved UAT هستند.
5. دسترسی SQL از Backend به `CAL2` و پوشش واقعی Canonical Day باید در محیط کاربر اثبات شود؛ اگر نباشد `BLOCKED` درست است.
6. `contractReference` و `rateEvidenceReference` از درخواست می‌آیند؛ نرخ و دوره از دامین LOAN/DPS2 مستقلاً اعتبارسنجی نشده‌اند. خروجی تنها تأیید فرمول آزمایشی است.
7. انتخاب تاریخ شروع معتبر از نسخه و تفکیک مدل `CONTRACT_MONTHS` از روزشمار جلالی برای داده‌های قدیمی نیاز به قرارداد Lifecycle جداگانه دارد.
8. سال‌های جلالی در آزمون واحد از Fixture کنترل‌شده استفاده می‌کنند؛ در Runtime داده CAL2 تنها مرجع مخرج و پوشش روزهاست.
9. ضرایب مالیات، خسارت و نرخ رسمی به‌طور پیش‌فرض صفر یا ۱۸٪ فرض **نشده‌اند**؛ `18%` فقط در Fixture غیرعملیاتی است.

## محدودیت حقوقی/بانکی

موفقیت فنی این Patch به معنی تطبیق مقررات تسهیلات، شناسایی سود، وجه التزام، مرابحه یا فروش اقساطی نیست؛ پذیرش کسب‌وکار همچنان الزامی است.
